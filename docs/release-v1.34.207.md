# v1.34.207 图纸资料库排版与预览交互

本版解决图纸资料库结果卡片被压缩、筛选控件重叠、质量异常入口拥挤，以及资料审核预览的页码与方向工具错位问题。预览使用独立样式的共用工具栏，初次打开按整个图纸适配实际可用区域。

## 变化

- 结果卡片按型号、客户、文件数量与时间分层，列表独立滚动，长内容不再互相覆盖。
- 常用搜索、计划周、客户及审核不通过留在筛选栏；其他资料状态和 SOP 状态放入更多筛选，已选条件可见、可清除。
- 当前资料突出名称、退回原因和处理入口；治具、审核状态、SOP 属性等保留在资料详情，文件列表改为浮层，打开不压缩图纸。
- 图纸和 SOP 的本版上传时间、内容变更时间与履历仍可查看。
- PDF 和图片预览共用翻页、缩放、适屏、适宽、方向、全屏工具；阅读方向操作集中在一层浮窗，保存反馈使用玻璃通知。
- 鼠标在图纸上直接滚轮缩放，以指针处为中心；列表上的滚轮继续滚动列表，放大后支持按住拖动查看。
- 初次进入只有 SOP 的产品时自动预览现有文件，退回资料优先定位到问题文件。

## 验证

- TypeScript 检查、预览手势、阅读方向及计划周专项单元检查通过。
- 使用本地隔离 PostgreSQL 与 S3 的真实上传资料，在浏览器验证 PDF、图片、长型号、长退回原因、文件浮层、滚轮缩放、方向保存与多个窗口尺寸。
- 实际完成“保留原文件说明后重提”和“更换 SOP 后重提”两条退回处理路径；重提后双方重新审核。
- 验证仅有图纸且需要治具、没有 BOM 的资料，品质先审、主管后审，两方均通过后允许打印。
- 最终镜像、匿名层校验、两套空数据库启动及镜像页面验收另记于发布验收记录。

## 升级

无需新增环境变量或数据库迁移，无需重新上传文件。本版保留图纸或 SOP 任意一种即可送审、主管与品质无先后且必须双方通过、BOM 与治具准备不阻塞资料审核和打印的既有规则。镜像交付与正式 Sealos 环境切换分别执行。

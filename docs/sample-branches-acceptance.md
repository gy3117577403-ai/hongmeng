# 样品新品与老产品计划实施约定

用户确认：老产品仅审核图纸资料；主管与品质顺序不限、双方通过，管理员可完成双方审核。老产品不要求扫码、采集、照片、工序、工时或 SOP。新品保留既有采集与整包审核规则。新品与老产品完成后均进入成品仓待入库，备注固定包含“样品完成”，记录现场完成日期；实际入库和发货继续由仓库确认。

## 必须完成

- 新建、编辑、Excel 导入/导出区分新品 NEW 与老产品 REPEAT；任务类型属于本次计划，复用产品图纸档案。
- 独立计划周：本周、下周、历史周、待排期、往期未完成；调整排期不复制任务、不改变出货日；历史无可靠排期保持空。
- 两类任务均有图纸上传/预览/版本关联，复用资料审核和退回处理；不因 BOM、治具或缺料阻止图纸审核和已审打印。
- 新品保留已有采集、照片、整包审核、归档、软删除和正式资料来源记录。
- 老产品图纸双审通过后可开始制作，分批登记完成量；无完成结果审核；服务端阻止绕过图审、重复完成和超量。
- 仓库配料直接关联样品任务，不伪造量产工单；统一采购/客供异常和物料跟进，仓库确认闭环。配料需求可人工录入，不强制 BOM。
- 改数量/取消/删除同步配料状态并保留历史，已配料需复核。
- 两类完成与成品仓待入库在同一事务执行、幂等、数量守恒，历史已完成样品不自动重复入仓。
- 紧凑橙色 2.5D 工作台：浮起的选中态、明确主操作、独立滚动、大预览、滚轮缩放、玻璃通知；平板、窄屏和减少动效适配。
- 按周/分页读摘要，详情按需加载，避免全量照片与采集记录拖慢列表。

## 验收

单元与真实 PostgreSQL 迁移/集成；新品与老产品 HTTP 闭环、图审/权限/版本冲突、分批完成与重试、采购和客供缺料、入库/发货数量；真实浏览器 1366×1024 和宽屏操作、图纸预览/上传、导入导出下载；全量项目检查；固定版本 CI、杭州镜像完整匿名拉取与两套干净数据库/对象存储启动。交付镜像不等于切换 Sealos。

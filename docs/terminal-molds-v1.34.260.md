# 端子调模：专模、组合调模与补录时段

## 使用入口

- 电脑端：技术与资料 → 端子调模 → 刀片 · 专模。
- 手机端：原有手机调模二维码，仍使用 `/tooling-mobile`。
- 开始调模先选端子，再选刀片调模、专模调模或组合调模。
- “补录时段”分已完成与仍在进行。已完成提交历史工时；仍在进行补记开始时间后继续计时。

## 数据规则

1. 一个专模型号一套实物，位置 01–20；与刀片盒 001–100 分开编号。建专模无需登记四把原配刀片。
2. 组合调模仅记录替换刀位，其他刀位保持原配。实时领用占用一套专模及选中的外借刀片，不生成额外库存。
3. 完成默认原位归还、原配已装回。未恢复原配、维修、留在设备上均不可再次领用。恢复原配前还须归还留在设备上的外借刀片。
4. 完成记录进入端子历史；下次选择端子可带出最近的专模或刀片组合，实物选择以当前库存为准。老版正式刀片方案继续保留。
5. 完成时段补录只保存使用快照和工时，不占用或归还当前库存。补记开始会立即占用当前工装，劳动起点使用实际开始时间。
6. 同一员工不能同时开启两个实时作业。允许在实时作业期间补录其他不重叠的已完成时段。调模、协助工时均校验重复时段。
7. 补录需填写原因，结束晚于开始且不晚于现在，单次不超过 24 小时。普通协同账号可补近 7 天；更早由管理员处理。
8. 起止时间使用中国标准时间。跨日工时分摊到实际日期，暂停不计有效工时；重复提交使用原操作标识，不重复领用或生成工时。
9. 日/周/月统计增加调模方式和记录来源筛选。CSV 增加专模、归属位置、补录原因与来源。
10. 权限沿用现有技术模块：只读查库存与记录，协同可报工和维护库存。未绑定员工的账号不能报工。

## 页面与交互

- 刀片库存改为全宽列表：可用整套、可用散刀、使用中、待维修、盒子位置。点行打开详情抽屉，关闭保持列表和筛选。
- 专模列表直接显示型号、可用数量、位置、状态及使用人；维护动作在抽屉内完成。
- 手机纯专模表单只保留端子、模式、专模型号；组合调模按需添加替换刀位。
- 表单内部滚动，底部提交按钮固定可见。360/390 像素宽手机及 1366×1024 平板验证。
- 正在计时仍提供“补录时段”，限制为不重叠的已完成时段。

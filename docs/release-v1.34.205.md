# v1.34.205 图纸资料库计划周筛选

选择本周、下周或指定周时，计划中心生成的关联图纸可能查询为空。原因是计划日期按上海时间中午保存，而资料库使用当天零点时间戳精确匹配。

本版按上海时间周一整天的日期范围匹配计划周，兼容中午、零点和历史 UTC 零点数据。图纸资料库列表、关联批次数、资料审核及治具准备的周筛选使用同一匹配方式；相邻日期和相邻周不会混入。

图纸资料可见性继续独立于 2026-09-21 的审核生效范围。本周历史资料可以查看，生效范围外的计划不会因此新增审核要求。

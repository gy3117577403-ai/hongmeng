# v1.34.204 — 图纸与 SOP 退回、技术处理和重新审核

主管或品质审核时可以只退回选中的图纸或 SOP，必填原因，可补充页码、位置和说明附件。图纸资料库按实际问题文件标记“审核不通过”，新增独立筛选与“已提交复核”筛选，可与计划周、客户和关键词组合使用。

技术人员在图纸资料库的“退回处理”抽屉中处理：上传替换文件并说明修改，或保留原文件并填写技术解释。全部退回事项处理完成后一次提交新审核轮次；主管和品质顺序不限、必须都通过，管理员可分别完成两项签名。原文件、退回原因、技术回复、旧签名和版本均保留。一般上传、删除或取消选择文件不能绕过未关闭的退回事项。

## 文件与打印

- 图纸和 SOP 显示本版上传时间、内容变更时间，履历显示首次上传、各版操作人和历史下载。技术解释、审核、备注编辑不算文件内容变更；无法确认的历史上传时间不补造。
- 同一问题文件被旧工单引用时，技术重新提交会将这些绑定接到修订轮次，仍需双方通过才能打印。无关历史版本的绑定不改写。
- 页面显示关联工单及历史打印次数；已发出的纸质资料仍需人工跟进替换。
- 缺 BOM、BOM 未确认、治具未匹配或库存不足不阻止资料审核与审核后的正常打印。
- 保持大幅资料预览；原因处理和时间履历使用不挤占版面的玻璃抽屉。

## 数据和通知

新增迁移 `20260920130000_document_return_workflow`，保存逐文件退回事项与说明附件元数据，附件继续存储在 S3。历史仍处于退回且没有后续轮次的资料生成“历史整包退回（未指定文件）”事项，不伪造曾经退回的具体文件，不清除旧审核记录。

退回通过站内待办通知提交人、原文件上传人及审核设置内选定的技术处理通知人员；重新提交后进入审核人员待办。沿用既有账号权限与审核设置，没有新增环境变量。

- 全量测试 1225 项通过，207 项按数据库等运行条件跳过；相关数据库测试另行执行。

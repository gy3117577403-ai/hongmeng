# v1.34.286 个人垫付快速报销

基于本次核对的最新已发布版本 v1.34.284。发布源码提交：`2e907c2176f8ae559790f874d1af369b7bb694c7`。

## 交付行为

- 个人垫付采购统一进入“快速申请报销”：一个窗口、一套收款信息、一次提交，同一实际垫付人生成一张 BX 报销单。
- 旧收款人写法、开户银行、卡号、空白字段，以及不同供应商、日期、采购申请不会把同一垫付人的记录拆组。
- 自动带出该垫付人最近一套完整收款信息，可在本次统一更改；采购明细默认收起，支持展开核对和移除项目。
- 默认申请全部可报销余额；其他信息展开后可减少本次金额、填写期望付款日期和备注。附件统一归到本张报销单。
- 翻页保留勾选、当前页全选/取消、选择全部筛选结果、仅保留可申请项目以及跨页导出继续有效。
- 历史采购未登记实际垫付人时，由经办人在本次统一确认并留存快照。已有分次报销确认的身份用于后续余额校验；已登记且仍欠款的停用人员可以继续办理报销。
- 原采购收款资料、历史付款、发票、入库数量和库存流水保留。不同实际垫付人、不同币种、不同业务来源或混合对公结算会明确拦截。
- 保留版本冲突、未结退款、金额更正复核、余额占用、事务回滚和幂等校验。已有历史分组资金单继续兼容。
- 审批、财务登记付款沿用资金流程，一张报销单可查看和导出每项采购明细。

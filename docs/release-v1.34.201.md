# v1.34.201 单类生产资料审核与打印

仅提供图纸或仅提供 SOP 的产品可以提交主管和品质审核；两种资料都没有时仍不能送审。治具选择可以先保存，不受文件上传限制。需要治具的产品继续要求确认 BOM，库存短缺不拦截已审核工单打印。

- 共用校验覆盖送审、审核、计划状态、同步和治具申购，保留文件身份、版本与审核签名校验。
- 页面按实际资料切换预览，空类别显示 0，已具备提交条件的草稿显示“可提交审核”。缺少多项条件一次说明，审核确认文案只列本版本实际资料。
- 主管和品质可按任意顺序审核，管理员可分别完成两项；双方都通过后才可打印。
- 打印增加“工单 + 现有资料（自动匹配）”，逐单冻结有效资料，可混合打印仅图纸、仅 SOP 和双资料工单。显式选择不存在的类别仍给出具体提示，不生成无效文件或空白页。
- 保留 2026-09-21 生效范围、历史版本与已发工单引用。补传或替换文件产生新版本，不能继承上一版审核结果。
- 没有新增数据库迁移或环境变量。

验证：新增单类资料数据库流程覆盖草稿兼容、无文件治具选择、两种审核顺序、混合打印、申购、缺货、补传版本和已删除文件。发布沿用全量 CI 及杭州镜像验收。

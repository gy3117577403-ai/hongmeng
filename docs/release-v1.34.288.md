# v1.34.288 其他工时批量同意与加载优化

基于最新成功发布的 v1.34.286（`2e907c2176f8ae559790f874d1af369b7bb694c7`）。本次只修改其他工时审批及其加载方式，员工工时计算服务保持不变。

## 使用方式

在“其他工时 / 其他工时审批 → 管理台账 → 待审批”点击“批量审批”。可勾选单笔、全选本页、选择当前筛选下全部可审批记录。翻页保留选择，改变筛选范围清除选择并提示。确认弹窗展示固定的记录快照、笔数、总时长和明细；新收到的申报不自动加入。

全部按各自原申报时长通过。核减或退回继续使用单笔流程。沿用既有审批范围、禁止自审、版本检查、员工事务锁、审计与待办更新。调模来源仅允许原时长通过；需要修改时仍回原调模台账。

前端按 30 笔分批提交，每笔使用既有事务。单笔冲突或失败不回滚其他成功项。批次标识存入既有审批轨迹，用于网络响应丢失后的安全重试。成功、跳过、失败分别展示，未成功项保留选择并可查看详情。一次全选最多 1000 笔，超过时要求缩小筛选，不静默截断。

## 加载优化

- 新页面使用精简分页列表，保留必要字段、附件计数及最近退回原因；完整处理轨迹和附件信息在详情中读取。
- 汇总独立加载，翻页不重复统计。分类独立读取，员工选项仅在需要时加载。旧列表接口、导出及其筛选口径兼容。
- 基础详情先展示，考勤损耗摘要独立加载，同日申报和生产时段明细展开后读取。未加载的数据不显示为零。
- 当前操作者可审时直接确认审批人可用，避免每次查全体有效账号。切换记录时取消过时请求。
- 照片使用按需生成的 256 像素 WebP 缩略图，派生文件保存在对象存储；点击查看仍使用原图。缩略图失败回退原图。缓存重新校验前必须验证登录、访问权限和软删除状态。
- 列表和详情接口附带 Server-Timing，便于后续定位数据库、网络与首屏等待。

## 工时及兼容边界

待审批其他工时仍按既有规则计入实时工时。原时长通过只确认状态，不再次累加工时；保留调模毫秒精度。核减、退回、撤回、作废、更正和按日期生效的调岗统计沿用现有服务。没有新增数据库迁移或必填环境变量，不更改生产数据和 Sealos 部署。

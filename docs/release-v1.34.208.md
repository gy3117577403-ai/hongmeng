# v1.34.208 首件检验查询与上传记录

首件页面改为紧凑工作台，选择工单即显示全部工序的首件记录，解决上传后被工序或日期筛选隐藏、难以找回的问题。

## 功能与口径

- 顶部收紧，保留检验类型、搜索和常用筛选，工单、记录、凭证三栏独立滚动。
- 全部、未完成、已完成按工单统计，筛选与数量在完整数据上计算后分页。
- 工单有至少一份有效、正式提交的首件记录即计为已完成。草稿不计，作废后重算；合格、不合格、待判定独立显示，不与生产完成混淆。历史在线表单同样保留。
- 默认展示工单下所有工序的记录，可通过工序下拉筛选；历史退役工序与未指定工序记录继续可查。
- 最近上传跨工单显示记录，支持我上传的、型号、工单、客户、检验人和文件名搜索，以及计划周、检验结果、草稿、上传日期或实际检验日期筛选。
- 实际上传事实来自附件与上传履历；首次上传、最近上传、上传人、正式提交、实际检验、最近变更分别呈现，不用草稿创建时间冒充上传时间。
- 在未完成队列保存提交后，工单从待办移出但保留本次凭证预览，可继续处理下一条。
- Excel 与附件 ZIP 沿用当前记录筛选，增加上传与变更时间列；回收站、补传、修订原因、原始明细和历史记录继续保留。

## 验证

- 独立 PostgreSQL 验证跨工单、分页、草稿与正式提交、不合格结果、作废恢复、历史表单和工序、日期与上传人筛选。
- 真实 S3 上传、提交、按文件名找回、Excel 和 ZIP 字节内容通过接口验收，新增检查纳入发布与杭州镜像流水线。
- 浏览器验证未完成队列上传 PDF 后保留预览、第二页选择、最近上传与我上传的查询，检查 1366×1024 和 1280×720 布局。
- 最终镜像身份、匿名下载和两套空数据库启动单独记录在交付验收文件中。

## 升级

无需新增环境变量或数据库迁移，已有首件记录与附件可直接查询，无需重新上传。该版本不增加首件审批或生产阻塞条件。镜像发布与 Sealos 正式环境切换分开执行。

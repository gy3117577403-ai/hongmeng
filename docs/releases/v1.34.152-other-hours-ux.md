# v1.34.152 其他工时申报与审批交互

手机扫码直接进入紧凑的“填写申报 / 我的申报”双视图。桌面保留左侧台账与右侧详情，将操作和核对信息放在处理位置，减少长期占据页面的说明及通知。

## 申报

- 手机仅提供填写帮助，不展示达成率公式；桌面标题旁“说明”打开计算口径。
- 删除安排人、样品任务的填写控件。旧申报已填写的内容放入“历史补充信息”，编辑草稿不会清空历史字段。
- 时长默认为空，提供 30、60、90、120 分钟快捷选择。事项用按钮选择，更多分类按需展开。
- 照片可先上传并保留到 S3，工作说明、时长及补报原因可以稍后补全。草稿允许 0 分钟，提交必须满足正整数时长、工作说明及适用的补报原因。
- 手机底部固定保存与提交操作，使用当前页面的安全区域；视口因键盘缩小时恢复自然布局。上传失败保留已成功照片，并允许重试或移除剩余失败照片。
- 填写和记录切换保留未保存内容；离开、换账号或改填其他记录时提供继续填写、放弃修改、保存后离开。重复操作受客户端忙碌锁、服务端幂等和版本校验共同约束。

## 查询与审批

- 手机按日期显示申报卡片，状态快捷切换，搜索、日期、事项放入筛选弹层。点卡片打开详情，关闭后保留原列表位置和筛选；下一页采用加载更多。
- 组长、主管、管理员从独立的审批管理入口进入管理台账，沿用现有审批范围及权限。
- 桌面提供待审批、已处理、全部。已处理包括通过、退回、作废；通过或退回后待审批队列自动选择下一条，队列为空时显示已处理完。
- 普通通过直接完成；核减、退回、更正和作废按操作再要求原因。已通过记录把维护动作收进更多操作，保留处理轨迹。
- 成功消息为短暂浮动提示，不占据页面高度。错误原因保留到处理；记录本身仍有状态标签。
- 状态标签只筛选记录，待审批笔数和已通过小时数按同一员工、权限、日期、事项及搜索范围统计。仅看更正与状态筛选取交集，不覆盖权限或其他条件。导出沿用同一筛选条件。

## 工时口径与迁移

保持既有计算规则：

```
达成率 = (完成工时 + 已确认损耗工时 + 已批准其他工时)
         ÷ (实际出勤工时 × 0.95) × 100%
实际出勤工时 = 正常出勤 + 已确认实际加班
```

新增 `20260910103000_other_work_partial_drafts` Prisma 迁移，仅放宽草稿的分钟数下限。待审批及其他非草稿记录仍须至少 1 分钟，批准时长仍不能超过申报时长。无历史删除，照片继续使用 S3 和软删除。保留 v1.34.150 的按日期生效调岗口径。

本版不变更二维码的永久入口 `/field-report/other-hours`。更新应用镜像后，现有二维码继续使用。

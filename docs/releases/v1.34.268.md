# v1.34.268 — 样品计划图纸替换与订单回收站

样品计划取消图纸主管/品质双人审核，提供原订单内直接上传、替换和历史查看，并把删除订单放入订单行的更多操作。量产图纸双人审核及新品试制采集数据整包审核继续保留。

## 使用入口

- 计划中心 → 样品：图纸列显示待上传、已上传、文件数量及版本。
- 订单行 → 上传图纸 / 替换图纸：比较当前与新文件，填写说明后保存；支持图纸与 SOP。
- 图纸与更换记录：查看当前资料、旧文件、操作者、更换时间与原因。
- 更多操作 → 删除订单（系统管理员）：查看数量和计划工时，选择或填写原因，移入回收站。
- 顶部回收站：填写恢复原因和原任务编号后恢复。

## 数据与流程

替换只修改本样品订单使用的文件快照；同型号其他订单、共享档案当前文件不被联动覆盖。订单号、二维码、采集数据、照片、配料和报工记录继续关联。文件存于 S3，元数据和审计存于 PostgreSQL；完成记录冻结当时文件版本。

制作中更换需要确认已通知现场；非待开始订单必须填写说明。勾选物料变化时，将仓库重新置为待核对并留下协同记录。已完成订单允许资料更正，不撤销完成数量或成品入库，也不能借替换重新配料。

删除使用可恢复软删除。采集提交包仍在审核中的订单需先撤回；制作中需确认已停止现场制作。恢复原制作中订单时回到待开始，防止自动续做。已完成数量、成品仓及历史资料保留。

## 升级

新增 Prisma migration：202610140001_sample_order_documents。镜像启动按现有流程自动执行迁移。历史样品订单取消图纸审核标志，并冻结各自原审核包或当前档案的图纸/SOP元数据；历史完成记录优先冻结其审核包。样品专用资料和历史引用的对象不会被共享档案清理误删。

本版本不修改真实账号密码、员工审批归属，也不自动切换 Sealos 生产镜像。

## 发布检查修正

v1.34.267 在镜像构建前被既有端子调模测试拦住：历史补报跨上海午夜时会正确产生两条日工时，旧测试错误地固定要求一条。本版本修正测试的每日条数、累计工时及当前日统计断言，不修改调模业务逻辑。样品功能沿用上一提交。

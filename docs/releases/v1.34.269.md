# v1.34.269 — 样品图纸替换、订单回收站与上传保存同步

包含 v1.34.267 的完整样品计划变更，以及 v1.34.268 的跨日测试修正。样品图纸不再要求主管/品质双人审核；采集数据审核和量产资料审核继续保留。

## 样品操作

- 计划中心 → 样品 → 订单图纸列：直接上传、替换、查看当前版本和更换记录。
- 替换仅作用于该样品订单，保留订单号、二维码、采集照片、配料、报工和完成记录；旧文件继续可查。
- 订单行更多操作 → 删除订单：管理员填写原因后移入回收站；制作中要求确认停止，审核中的采集包要求先撤回。
- 顶部回收站可恢复原订单；制作中订单恢复为待开始，保留原有实际完成和入库事实。
- 对话框使用固定操作栏与内部滚动，显示实际文件、数量、工时和影响范围。

## 发布验收发现与修复

v1.34.268 的镜像验收在量产资料编辑中暴露了上传与保存之间的版本竞争：上传成功后依赖全局异步同步队列，当前产品可能未及时生成新的资料包，弹窗保存了旧包编号。

上传接口现在在同一事务内同步该产品的资料，并返回该次写入的包编号、版本及文件列表。弹窗直接采用这份回执，不依赖全局队列推断自己的上传结果；后续并发修改仍由原有版本冲突校验阻止。

浏览器回归等待当前产品初始化完成和本次上传的确切回执，校验新包包含本次 SOP、旧已签署资料不被改写，再执行保存与送审。

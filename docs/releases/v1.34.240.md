# v1.34.240 物料任务分配与本人接收

物料跟进原先只显示“分配并接收任务”的提示，实际入口藏在交期表单内，且修改负责人会直接进入跟进中。本版将分配、本人接收、转交放到右侧固定操作区。

- 未分配时直接显示“分配负责人 / 我来接收”。负责人支持按姓名或账号查找。
- 分配给同事后保留待接收状态，显示具体接收人；被分配的人本人接收后才进入跟进中。接收不要求先填写进展或交期。
- 处理中可转交负责人。转交保留缺料数量、累计到料和原交期，新的负责人重新确认接收；时间线保留前后负责人、操作人和交接说明。
- 普通协同人员可补充进展，并可接收明确分配给自己的任务；分配、转交和到料字段继续遵守原操作权限。
- 已输入的进展在分配或接收后继续保留。负责人不再藏在“更新交期 / 到料”中，避免普通进展隐式变更责任人。
- 仓库与物料跟进共享负责人、接收时间和处理记录。原来的部分到料、仓库核实及配料完成规则保留。
- 选择负责人在当前面板内展开，支持键盘操作、加载及错误反馈。弹层根据可用高度内部滚动，保持页面在一个视口内。

数据库迁移 `202609250001_material_assignment_acceptance` 仅新增可空的 `assigned_at`、`accepted_at` 字段。历史记录不补造接收时间，也不修改原进度或物料数量。

验收包括分配与接收分离、非本人不能代接收、并发冲突、转交保留物料事实、普通文字进展、仓库同步及 1366×768 / 1366×1024 页面操作。发布证据保存于本地交付目录；镜像发布不代表生产环境已切换。

# v1.34.156 异常快处

品质人员可在质量管理的“异常快处”中选择工单、填写问题与现场处理说明、上传照片，直接保存记录或发布警示。快处无需审批，不创建工时、订单成本或重大异常统计。

## 现场操作

- 默认只警示所选工单。明确选择“产品持续警示”后，按现有图纸库身份应用到同产品后续工单；产品资料变化时停止生效，重新发布需确认当前资料。
- 工单预览、生产质量详情、图纸库产品详情及手机报工接入同一生效警示接口。已有工单二维码可进入快处并带入工单，不需重新印码。
- 桌面左侧列表、右侧详情；手机使用全屏表单和详情。搜索、状态、日期、分页及回收站支持完整查询。
- 拍照、选择多图、粘贴、拖入；可添加方框或箭头标注，保留原始图片。支持 JPG、PNG、WEBP，每条最多 12 张，单张 20 MB，本次上传合计 32 MB。
- 上传显示进度；网络中断保留表单及图片，同一次提交重试不会重复生成记录。离开未保存表单会提示。

## 生命周期与数据

- 品质更新权限或管理员可发布、编辑、下线、删除；下线与删除可选简短原因。删除同时停止警示并进入回收站；仅管理员可恢复，恢复后保持下线。
- 每次变更生成版本和操作轨迹。并发操作使用数据库锁、提交幂等键与版本检查，避免重复或相互覆盖。
- 可转入重大异常，复用说明、图片对象与工单关联。原快处警示保留到正式异常发布，再交接下线一次。
- 照片保存在 S3，元数据及历史保存在 PostgreSQL。图片删除为软删除，历史证据保留，普通员工不能打开已下线或删除的现场图片。
- 可选择允许工单打印附页，使用现有“流转单 + 异常警示”打印模式。附页说明显示为现场提醒，不自动判定风险等级。已生成打印版本保留当时内容，当前警示以登录系统看到的状态为准。

## 数据库与运行

- 新增 Prisma 迁移 `20260910143000_quality_quick`，合计 148 项迁移。只新增快处记录、关联、图片与审计表，不改写现有质量业务数据。
- 容器端口保持 3000，沿用现有 PostgreSQL、S3、会话及站点地址配置；入口脚本启动时自动执行迁移。
- 版本 v1.34.156，目标 linux/amd64。镜像发布不代表切换 Sealos 生产应用。

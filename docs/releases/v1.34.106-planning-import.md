# v1.34.106 计划工艺关联与量产批量导入

本版本合并交付两项计划中心修复：产品已发布工序与工时的关联状态展示，以及量产计划的图纸库安全批量导入。镜像发布本身不等于 Sealos 生产环境已经切换。

## 任务一：计划中心工序与工时关联

- 产品已有正式发布的工序与工时、但计划尚未下达生成生产工艺时，计划列表显示“已关联 Vx / 下达后自动生成”，不再误报“待生成”或“没有工艺”。
- 已确认、生产中或已完成的实际生产工艺仍优先展示，不用产品库版本覆盖现场执行记录。
- 产品匹配先按明确引用和精确字段查找，再进行规范化兜底；有多个候选时优先选择唯一或资料更完整的正式产品，避免任意关联。

## 任务二：量产计划批量导入

### 导入流程

1. 在计划中心下载简化 Excel 模板并填写订单及排产信息。
2. 上传后只做预检，不立即写入订单或图纸库。
3. 预览页逐行显示“复用已有图纸库、恢复已删除图纸库、新建图纸库、重复跳过、冲突待选择、数据错误”六类结果。
4. 只有冲突行需要人工选择已有图纸库；错误行必须先修正模板并重新上传。
5. 确认导入后以一次数据库事务提交，任何一行失败都会整体回滚，避免半批成功。
6. 完成页和导入记录页保留批次、操作者、结果统计与错误信息，便于追溯。

### 图纸库保护规则

- 同一来源订单号和行号已经关联图纸库时，始终沿用原关联，不重新建库。
- 未明确关联时，先按图纸库编号，再按规范化后的“客户 + 型号/规格”匹配。
- 唯一有效匹配直接复用；唯一已删除匹配自动恢复并复用；没有任何匹配才自动新建。
- 出现多个可能匹配时禁止自动新建第三个图纸库，必须在预览页人工选择。
- 复用或恢复只建立订单关联，不覆盖已有图纸、SOP、正式工序工时等产品资料。
- 同一文件或目标周内重复的来源订单行会标记为跳过；批次提交使用请求令牌、数据库锁和序列化事务防止重复点击或并发导入造成重复数据。

### 简化模板

- 必填 9 列：来源订单号、订单行号、订单日期、客户名称、产品名称、型号/规格、订单总量、本周排产量、客户交期。
- 选填 5 列：计划完成日期、图纸库编号、客户等级、业务员、备注。
- 单次最多导入 1000 行；模板文件最大 10 MB，支持 `.xlsx`、`.xls` 和 `.csv` 预检。
- “订单总量”和“本周排产量”分别处理，不把本周数量误当成订单累计总量。

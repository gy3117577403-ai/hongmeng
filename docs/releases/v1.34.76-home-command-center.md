# v1.34.76 首页智能工厂指挥舱

本版本将登录后的首页重构为面向 1366×1024 横向平板的智能工厂指挥舱，并把消息提醒从简单入口升级为可持续处理的业务消息工作区。

## 首页

- 保留现有平台导航、全局搜索、业务入口和真实数据权限边界。
- 新增六节点生产协同运行中枢，覆盖周计划、图纸、生产、物料、质量和工时。
- 使用真实计划与业务数据驱动中心执行率、状态和底部洞察；无数据时明确显示 `--`，不制造样例指标。
- 加入 2.5D 分层、数据流动效、指针轻视差、键盘焦点和减少动态效果兼容。

## 消息提醒

- 新增待我处理、生产异常、质量、工艺、物料和系统六类视图。
- 支持关键词搜索、仅看未读、全部已读、单条已读/恢复未读和 1 小时后提醒。
- 稍后提醒时间持久化在 PostgreSQL；到期前不进入活动列表、未读数或紧急数。
- 分类来自通知来源和业务语义，继续复用现有通知与访问能力，不新增角色体系。

## 数据库

- 新增 `system_notification_recipients.snoozed_until`。
- 新增用户、稍后提醒时间和创建时间的联合索引。

## 验收边界

- 视觉与交互在隔离 PostgreSQL/MinIO 环境完成 1366×1024、1024×768 和 390×844 浏览器验收。
- 发布 GHCR 镜像不等于切换 Sealos 正式环境；正式切换需独立授权与验收。

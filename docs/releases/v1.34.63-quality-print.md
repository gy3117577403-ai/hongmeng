# v1.34.63 — 异常警示附页原图比例与分页

本版在 v1.34.62 的异常协同、产品警示和员工只读二维码流程上修复图片打印。

- 新上传的图片记录显示方向下的宽高和 EXIF 方向；原始 S3 文件不重新压缩、不裁切。
- 旧照片第一次用于新版预览或新打印任务时按原文件补读尺寸，仅缓存技术元数据。
- 新打印任务使用 `ASPECT_V1` 排版快照。按毫米指定图片真实宽高，避免 html2canvas 不支持 `object-fit` 导致拉伸。
- 自动省纸模式根据横竖图选择布局。同页同规格照片等大，奇数尾图保留同列宽；三张竖图可同排。
- 大图细节模式保留放大空间并按需续页，不强行缩小全部内容以凑一页。
- 每张图可选择是否随单打印、编辑图注、调整顺序。两张照片使用相同对照组名时保持并排同页；每组最多两张。
- 预览页显示预计页数，可切换排版试览。正式随单打印采用归档设置，试览不会暗改归档或既有打印任务。
- 空字段不占空间，长图注与长方案完整续页；尺寸读取失败或缺图时阻止生成有缺陷的正式文件，并给出明确提示。
- 既有打印任务沿用旧版页面清单和布局；需要新版排版时重新生成打印任务。旧 PDF 不会自动改变。

## 升级

容器启动运行 Prisma 迁移，新增 `quality_risk_attachments` 的图片宽、高、方向和打印对照组字段；累计 106 项迁移。保留原 PostgreSQL、S3 和公开域名环境变量。无需重新上传已有照片。

镜像发布及隔离环境验收不代表已切换 Sealos 生产应用。

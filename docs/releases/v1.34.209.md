# v1.34.209 首检和巡检日期归档

现场纸质首检表常常包含多个产品。新首检与巡检统一按报表日期上传照片或 PDF，创建时不关联工单、批次和工序。必填项只有日期和至少一份文件；名称自动生成，实际检验人、区域和备注选填。照片里的检验结论保留原样，归档状态不代表产品合格。

## 操作

- 默认显示全部日期，可按日、周、月、自定义日期查询；跨日纸表可填写结束日期，覆盖区间内查询只返回一份报表。
- 全部 / 已归档 / 草稿筛选，支持最近上传、我上传的、上传人及名称、备注、文件名查询。撤销按工单的完成 / 未完成统计。
- 日期列表独立滚动，右侧大图预览；支持列表折叠、适屏、适宽、滚轮缩放、方向保存及全屏。手机列表与预览分开显示。
- 新增支持多选、拖入、拍照、草稿和上传失败重试。补传成功后定位新照片，已有上传内容保持。每份文件不超过 20 MB，一条报表最多 30 份文件。
- 首次上传、最近上传、上传人、归档时间、变更时间分别保留。编辑已归档内容须写修订原因，删除使用回收站并可恢复。
- Excel 和附件 ZIP 使用当前筛选，ZIP 按类型、日期和记录编号组织。旧首检仍能按日期找回，原工单来源和检验结果可在时间与来源、历史明细查看。
- 旧首检扫码入口转到日期报表，不再自动绑定扫码工单。其他检验类型和工序报工继续使用原业务规则。

## 数据与升级

新迁移 `202609210001_first_date_archive` 只放宽 FIRST 的工单非空检查，保留其他类型约束；不改写任何旧记录。覆盖结束日期存入已有 JSON 字段。照片继续使用 S3 对象存储，元数据使用 PostgreSQL，无新增环境变量。镜像启动通过原 entrypoint 自动执行迁移。

## 验证范围

- 单元套件通过；数据库集成覆盖日期交集、同日多份、分页、筛选数量、首次 / 最近上传区别、软删除恢复、历史快照、旧工序记录兼容。
- FIRST 与 PATROL 的 HTTP/S3 验收覆盖无工单创建、必需附件、上传、补传、原件 SHA-256、方向下载、筛选、Excel、ZIP 内容一致性以及访问控制。
- 浏览器实际验证 1366×1024、1280×720 和 390×844 视口；新建、跨日期巡检、补传定位及鼠标滚轮缩放。

镜像构建、远程摘要与两套空库启动验收的最终证据单独交付。发布镜像不包含 Sealos 生产环境切换。

# v1.34.271 — 缺料归类、财务采购明细与采购执行分栏

基于已验证发布的 v1.34.270 及其最新开发提交 `57e9ca5f44946ed651d473c0596cc8882e25e326`，包含以下三项业务改进。

- 物料追踪与仓库配料增加「缺料」筛选；采购、客供、来源待确认继续作为来源维度。周订单和订单池均要求来源与未解决缺料属于同一条记录，历史已解决事项不混入当前缺料统计；缺料数量未知仍保留。
- 财务打款及资金申请导出为「付款汇总」「采购明细」两张工作表。明细包括采购品名、规格、数量、单位、单价和来源、商品金额、运费优惠及本单请款/付款分摊。新资金单冻结申请时快照，历史记录明确标注折算和关联依据。支持分次付款、关闭余额、撤回及后续再次请款的金额追溯。
- 采购执行增加「已审批待采购」「已采购」「全部执行」分类及计数，列表、金额、勾选和导出使用一致筛选；已完成仍进入原完成入口。采购登记支持六位小数成交单价，按数量计算后舍入到分。

## 数据库与部署

新增 Prisma 迁移 `202610150001_purchasing_unit_price`，为 `PcLine` 添加可空成交单价、商品金额及默认零运费/优惠字段和一致性约束。历史采购总额不改写，不补造历史成交单价。镜像启动按既有流程执行 Prisma migrations；须等待迁移完成后再验收页面。

沿用现有登录、业务经办责任、PostgreSQL 与 S3 配置。此发布任务交付杭州镜像，不切换 Sealos 生产应用。

## 使用与升级

保持现有 PostgreSQL、S3、登录及正式域名配置，镜像启动时自动执行 Prisma 迁移。无需新增必填环境变量。

- `人事与工时 → 其他工时`：申报、台账、分类筛选与汇总、导出、固定二维码。
- `协同与审批 → 其他工时审批`：单独的审批入口。
- 员工入口：正式域名下的 `/field-report/other-hours`。在正式站点下载二维码后张贴，二维码与具体员工、订单及登录令牌无关。
- 管理员、拥有相应历史班组范围的组长、主管中的一人审批即可；本人和本人代填的申请不可自审。
- 其他工时按批准时长全额计入个人达成，5% 休息余量只在出勤目标分母体现；订单成本和订单异常数据不被这些安排工时影响。

完整功能规则见 [版本说明](v1.34.149-other-work-hours.md)。批准后的历史更正需要保留原因、作废原记录并重新审批；不能直接恢复成已批准状态。缺考勤时工时保留，达成率显示待完善；正式服务切换后需使用原有真实考勤数据核对现场结果。

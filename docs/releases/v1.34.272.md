# v1.34.272 — 到料结果核对、采购资料后补与数量更正

基于 v1.34.271（`cd16c8576d44a9203831849a5d4cd9283d3e523d`），保留缺料与来源交叉筛选、采购执行分类、财务采购明细 Excel 导出。

## 业务变化

- 仓库与采购共用到料阶段及计数：缺料待到、部分到料、已到待核验、已到料待确认是否补齐、本项已解决。数量未知的到料记录不再直接断言仍然缺料，单列「待确认补齐」；新确认到料必须明确选择仍缺或本项补齐。部分到料和异常待补继续计入缺料，产品可配套数量仍由仓库单独确认。
- 同订单同型号的多项记录提示核对来源与实际需求。仓库可以填写依据、选择保留事项并撤销空白重复项；有发货或到料事实的事项不能用这个入口撤销。单项到料不会自动关闭其他来源的独立需求。
- 登记采购时收款人、开户银行、账号、月结账期及付款到期日期均可留空；不再自动预填本月账期。未约定付款日期明确标注。请款时仍须填写有效账户，首次补充不要求虚构变更原因；账期未确认的月结采购须分别请款或补齐账期后合并。
- 新增「补充收款与结算资料」，收货后仍可使用；保留已提交资金单的收款快照。空白采购资料不会擦除供应商已有的有效账户，最近账户查询跳过空值和 0 等占位值。
- 新请购数量不再默认 1，可以空数量保存草稿，正式提交必须填写正整数。数量与单位独立输入，单位提供常用选项并拒绝以数字开头的误填；采购列表、详情和采购登记中加粗显示数量。
- 历史「1 × 5件」明确提示待核对。现有采购审批负责人通过「核对数量与单位」填写依据并确认后更正。已有业务事实时只允许整数单位换算，同步收货、退货、取消数量及在库、领用等库存余额；原采购金额、收货凭据、退货凭据、旧库存流水及资金单快照保留。财务导出提示当前采购计量已经更正。

## 数据库与上线

新增两项 Prisma 迁移：

- `202610150002_material_arrival_outcome`：保存仓库明确核对的补齐结果，默认空值兼容历史。
- `202610150003_purchasing_quantity_units`：收货、退货及库存流水保存原始单位，并回填历史单位；未提交草稿允许空数量（数据库以 0 表示），提交与执行记录仍受正数约束。

镜像启动按既有流程执行迁移。迁移不批量修改实际采购数量、金额，也不自动关闭真实缺料。历史到料待确认及重复事项上线后仍需仓库依据实物核对；历史单位更正需有核对依据。

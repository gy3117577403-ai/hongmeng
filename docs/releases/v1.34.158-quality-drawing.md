# v1.34.158 — 图纸质量异常统一关联

异常快处现在直接选择图纸档案，进入图纸库原有警示面板。原“产品重大异常”入口更名为“质量异常”：重大异常归档警示标记为 A 级，快处警示标记为普通异常。已有内部风险等级、重大异常审批与归档流程保留。

## 行为

- 无需先有工单即可登记、上传图片并发布图纸警示。扫码进入时自动选中工单关联图纸，工单仅保留为来源记录。
- 当前及后续关联同一图纸档案的订单自动读取生效警示。补充图纸文件或修改资料说明不再让普通警示意外消失。
- 图纸页统一显示、计数并预览两类警示；普通异常可直接编辑、下线或删除。删除进入回收站，管理员恢复后仍保持下线。
- 新发布快处默认随工单打印，复用现有异常告知 PDF 与历史打印快照。A 级排在普通异常前；混合批次中无警示的工单仍正常打印工单页。
- 原快处记录能够由来源工单唯一确定一份有效图纸的，由迁移自动补齐关联并记录轨迹，保留原状态、图片和打印设置。多图纸或缺失关联的记录保留原工单范围，显示“待关联图纸”。
- 来源工单删除不阻断已有图纸警示维护；被普通异常引用的图纸档案计入资料删除检查。
- 已生成打印快照保持不变，重新生成打印使用当前生效警示。

## 验证与发布

- 新增 PostgreSQL 集成覆盖无工单发布、现有/后续工单继承、错误关联拒绝、历史来源删除、两类警示共同打印、下线与快照保留、旧数据迁移幂等。
- 保留并运行快处并发、权限、删除恢复、重大异常交接及发布版本检查；新增集成接入镜像 CI。
- 本机已验证拍照上传、图纸预选与切换、图纸内编辑删除、管理员恢复、员工查看原图和 PDF 下载，覆盖 1366×1024、1366×768、390×844 与 320×640。
- 使用 Prisma 新迁移 `20260911090000_quality_drawing_link`，应用启动执行迁移。附件仍在 S3，元数据仍在 PostgreSQL。
- 镜像目标为 Linux amd64，服务端口 3000。交付镜像须核对源提交、CI、杭州仓库匿名拉取和全新数据库运行结果；生产 Sealos 切换不属于本次发布动作。

CI 首次运行发现测试缺少专用 SESSION_SECRET；已在数据库测试夹具中补齐，仅用于隔离测试环境。v1.34.157 未发布镜像，正式发布使用 v1.34.158。

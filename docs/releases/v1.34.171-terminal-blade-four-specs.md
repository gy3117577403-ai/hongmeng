# v1.34.171 四刀位独立规格

刀片库原先允许一个型号选择多个刀位，但这些刀位共用规格和采购来源。现在型号与品牌只维护一次，上外刀、上内刀、下外刀、下内刀各自保存规格、尺寸 A/B、单位、材质、硬度、备注和多个采购来源。

- 编辑页按四张卡片展示，补充参数在对应刀位的独立窗口填写，保存按钮固定；手机按单列展示并提供刀位跳转。
- 规格完整时保存整组，缺项可以保存草稿；调模选刀读取当前刀位的规格和来源，不再读取型号上的共用规格。
- CSV/Excel 导入支持四刀位列，CSV 导出保留每个刀位的全部采购来源；旧格式仍可导入。
- 新增 Prisma 明细表，保留原型号 ID、旧资料和方案关联。旧单刀位资料直接继承；旧多刀位共用规格仅按原声明刀位继承并标记待核对，不推测未声明刀位。历史已发布方案保持原状态，未核对的规格需在刀片库确认后才能用于新的方案发布。
- 整组更新使用版本校验和数据库事务，未改动刀位的明细及采购来源保持不变，旧页面提交共用规格会提示刷新。

验证覆盖：解析与 CSV 往返、真实 PostgreSQL 明细隔离和回滚、迁移后历史外键保持、HTTP 保存/编辑/冲突/草稿/导入导出/发布选刀、平板与手机浏览器交互。发布流水线对源镜像与杭州匿名拉取镜像分别运行业务验收。

镜像发布与 Sealos 切换分开处理。本次不直接修改正式数据库或切换生产版本。

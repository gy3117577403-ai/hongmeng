# v1.34.161 — 样品交期与首页任务入口

在已完成或筛选视图中新建样品后自动清除旧筛选、打开新任务并更新任务链接；编辑时固定打开窗口时的任务 ID 和版本，自动刷新不会掩盖并发冲突。

样品计划默认显示未完成任务，日期、客户、等级、成员和交期预警筛选在服务端执行；统计覆盖全部符合条件的任务，列表分页不再受原 300 条截断影响。任务卡片增加当前排序下的序号、下达日期、出货日期和预警。CSV 导出使用相同筛选，覆盖全部匹配任务。

首页消息区域新增“样品”，提供未完成/已完成切换、型号搜索和分页；列表只显示产品型号，通过任务 ID 区分同型号不同批次。进入任务后“返回首页”恢复样品视图、搜索、分页和滚动位置。原有协同消息处理逻辑保持独立。

## 日期与兼容

- `due_date` 沿用原计划日期值，页面明确命名为计划出货日期；迁移不重写原值。
- 新增 `issued_date`、`warning_days` 和 `schedule_history`。历史下达日期保持空值，详情明确显示“未记录”和原系统录入日期，不将录入日期冒充下达日期。
- 新建任务默认当天为下达日期，允许填写实际计划日期。新模板可填写下达日期、提前预警天数；兼容旧模板的“计划日期/完成日期/交期”列，未提供下达日期的旧模板导入保持未记录。
- 预警按北京时间自然日计算；默认提前 2 天，可改为 0–30 天。完成或取消退出预警。下达日期已知时，出货日期不能早于下达日期。
- 修改日期或预警必须填写原因，使用现有任务版本校验、事务与任务锁防止覆盖并发修改，保留操作人、时间、原值、新值和原因。
- 保留现有样品采集、照片、整包审核、无资料完成、归档、软删除/恢复及图纸资料关联。

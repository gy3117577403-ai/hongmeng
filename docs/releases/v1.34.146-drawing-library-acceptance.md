## 本次交付的行为

计划导入、手工建档、计划建档、工单资料同步和样品建档统一匹配规则。客户名称末尾的数字编号可与不带编号的名称匹配，规格统一处理大小写、全角字符与空白。名称中的地区括号、不同的明确客户编号、型号和版本仍参与区分。唯一匹配复用原档案；多个匹配要求选择；已删除档案要求管理员先恢复。已有明确工单关联不会因再次上传图纸而自动换到其他主档。

管理员在“图纸资料库 → 更多资料操作 → 删除图纸档案”填写原因并查看阻止项。未删除文件（包含非当前历史版本）、活动计划/批次、未完成生产工单以及产品工时等结构化引用都会阻止主档删除。文件全部已软删除且无阻止引用时，允许主档进入回收站。操作保留审计记录。

管理员在“资料回收站 → 已删除图纸档案 → 恢复图纸档案”填写原因后，恢复原编号和原有关联。恢复时再次检查同产品活动档案冲突。恢复主档不会自动恢复已删除文件，不会复制主档，也不会重新指派订单。

图纸库主列表按页完整加载，修复只显示前 600 条造成的漏查。数据库增加规格索引和引用保护，串行处理同产品建档，并防止资料上传、文件恢复、新业务引用与主档删除并发时产生悬空关联。

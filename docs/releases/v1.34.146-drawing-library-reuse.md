# v1.34.146 图纸库复用与管理员回收站

量产计划导入中的客户名有时不带数字编号，历史图纸库却使用“客户(编号)”，此前会新建空档案。本版统一产品匹配：规格使用 NFKC、大小写及空白规范化；客户仅识别末尾纯数字括号编号，保留“伽利略（天津）”等名称内容。明确不同的客户编号、不同客户、型号版本不可自动混用。

导入预览与提交使用一致候选规则和完整规格检索。唯一活动档案复用原 ID；多个匹配要求显式选择，提交重新校验候选和身份；没有活动档案但存在删除档案时要求管理员先恢复。建档按规范化客户及规格串行化，重复提交仍由原导入事务保证幂等。手动建档、计划建档、工单资料同步、样品建档同时使用该规则。

管理员在图纸库“更多 → 删除图纸档案”查看引用检查并填写原因。没有未删除文件（包括非当前历史版本）、活动计划/批次/未完成工单及产品工时、SOP、产品参数、样品和质量引用的档案可以软删除。文件已软删除且无其他阻止引用时允许删除主档。原 ID、软删除文件历史、S3 对象、历史业务关联与审计日志保留。

“资料回收站”提供管理员恢复入口，恢复要求原因并检查活动同产品冲突。恢复主档不会复活已删除文件、复制主档或重新指派计划；原有关联继续使用原 ID。普通账号即使直接请求接口也不能删除/恢复主档。原图上传只更新已经明确关联工单的图纸就绪状态，不再自动更换已有档案关联。

数据库迁移 20260909150000_drawing_identity_lifecycle 仅新增规格检索索引和活动档案引用保护触发器，不执行历史档案合并、关联改写或资料删除。触发器与删除事务的行锁配合，防止上传、文件恢复或新业务引用和主档删除之间的竞态。

资料库页面分页读取完整检索结果，解决原来只显示前 600 条造成的漏查。新增回归覆盖客户编号/全角字符、型号版本、多个候选、已删除匹配、并发建档、历史文件、业务引用、删除/恢复审计、并发文件引用。发布流程执行 PostgreSQL 集成及真实镜像上的 HTTP 导入、上传和权限验收。

历史重复档案不会自动归并。本版保持既有已下达订单的显式关联、工艺快照和工时，历史数据修复仍须核对对应档案及生产事实后单独执行。镜像发布与 Sealos 生产切换分开验收。

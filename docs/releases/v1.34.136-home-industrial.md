# v1.34.136 — Industrial collaboration homepage

The homepage now presents its six collaboration modules in a light industrial scene. Selecting a module highlights its connections, presents its business summary, and filters related notifications. Module links, pending-work drawers, search, and metric details remain live application controls.

## User-visible behavior

- A layered industrial floor and separate assembly workcell replace the flat backdrop; the left navigation, header, cards, inbox, and metrics use one light orange-accented visual system.
- Module selection survives returning to the homepage in the same tab. Selecting a module resets conflicting notification view/search/unread filters; selecting a notification category clears the module highlight without overriding the user's category.
- The central instrument and metric cards open an accessible detail panel. Drawers trap keyboard focus, Escape restores the trigger, and Ctrl+K closes the panel before opening search.
- Standard and quiet motion preferences are available. Fine-pointer parallax is disabled for touch and reduced motion, and background movement pauses when the page is hidden.
- The center is labelled as a weekly completion rate. The former on-time delivery percentage is labelled as the current week's non-overdue share. Drawing counts describe work orders awaiting drawing confirmation, not file counts. Open issue totals use a separate aggregate, not the truncated preview list.
- Notification totals distinguish unfinished messages from messages requiring action. Empty states link to other populated categories. Read, completion, restore, snooze, and search behavior use the existing authenticated APIs.
- Missing data uses an unknown state; decorative asset failure offers retry without blocking business controls.

## Scope and compatibility

Based on v1.34.135. No database schema migration is added. Existing login, access scoping, PostgreSQL metadata, S3 storage, and soft-delete behavior are retained. The release publishes an image; production configuration and Sealos traffic cutover are separate operations.

## Assets

Both assets were created with the built-in image-generation tool for this release, then resized/encoded as WebP with Sharp. The workcell uses a white background and multiply blending; it is not claimed to have an alpha channel. No UI text or business values are baked into an asset.

- `public/assets/home/industrial-floor-v134136.webp`: 1448 x 1086, 88,872 bytes. Prompt: a pale isometric precision electronics factory floor, quiet white equipment at the edges, orange conduits, generous open center, soft upper-left illumination; no UI, text, logos, or charts.
- `public/assets/home/industrial-workcell-v134136.webp`: 512 x 512, 26,116 bytes. Prompt: an isolated orange robot, white electronics assembly bench and material bins, matching isometric perspective and soft lighting; solid white background, no text. A first output with simulated checkerboard transparency was rejected and regenerated.

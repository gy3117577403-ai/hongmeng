# v1.34.264 — 小模块授权与管理员审批交接

本版本将七类业务授权拆分为 61 个独立入口：40 个业务小模块、21 个报表分支。业务模块支持未开通、只读、协同；报表支持未开通、只读。菜单、页面、接口与业务动作共同校验，保留手机报工、样品库、样品采集的独立授权。

账号管理增加「审批交接」。管理员选择交出账号及接替员工，先预览待办、退出通知、所需业务权限，再确认交接。已存在的资料变更、资料审核、采购通知退出管理员收件箱，原业务处理人的记录保留。已适配的其他管理员审批及后续同类待办交给接替员工，不授予系统管理员身份。

交接清单处理重大质量最终审批、其他工时审批、报工补正及撤回、工艺变更审批。涉及本人提交或本人已参与的独立审批保留原审批人；未适配的审批类型阻止整个交接并列明原因。接替员工停用、权限被撤销或存在自审冲突时，后续待办保留管理员兜底。更换已有接替人需先处理原交接，不静默覆盖。

## 升级与账号操作

- 镜像启动使用现有 Prisma migration 流程，新增迁移为 `20261009150000_submodule_approval_handoff`。
- 历史大模块权限按原只读/协同等级、授权期限展开。已有细分授权不被宽泛权限覆盖；相关旧登录会话失效后需重新登录。
- 业务交接是显式操作，升级镜像不会自动改管理员密码或修改真实员工审批关系。
- 入口：系统管理 → 账号与访问管理 → 审批交接。先核对张豪的在职员工绑定及小模块权限，选择管理员与张豪并预览。旧岗位授权需先在模块权限页确认保存；班组范围授权不自动扩为全公司。
- 管理员密码通过原密码管理入口修改，或在具备生产容器授权的终端使用下述一次性工具。密码不进入源代码或镜像。

## 容器内一次性交接工具

镜像包含 `/app/ops/admin-business-handoff.cjs`，默认只输出预览；管理员用户名默认 `admin`，目标员工姓名默认 `张豪`，必须唯一匹配有效员工账号。

```sh
node /app/ops/admin-business-handoff.cjs
```

管理员用户名不为默认值时设置 `HM_HANDOFF_ADMIN_USERNAME`。预览确认后，通过运行环境安全注入 `HM_ADMIN_NEW_PASSWORD`，并设置 `HM_HANDOFF_FINGERPRINT` 为本次预览返回值、`HM_HANDOFF_ALLOW=authorized-admin-handoff`，再运行：

```sh
node /app/ops/admin-business-handoff.cjs --apply
```

工具在一个数据库事务内完成密码哈希更新、旧会话失效、审批交接和审计记录；清单变化或存在阻断项时整笔回滚。请勿将密码写入仓库、镜像构建参数、共享脚本或日志。执行后清除临时环境变量。该工具不在镜像启动时自动执行。

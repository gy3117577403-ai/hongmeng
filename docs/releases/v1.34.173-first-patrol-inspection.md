# v1.34.173 首件检验与巡检报表

首件检验按产品工单、批次和具体工序保存结果及照片；巡检报表按实际巡检日期归档整份纸质报表。品质一次抽检多个产品时可以直接批量上传照片或 PDF，无需逐个产品建立巡检记录。

- 首件工作台保留工单、工序、记录和固定预览区域。工序选择支持名称、序号搜索及较长工艺路线，同名工序以实际工序 ID 区分。扫码选择首件工序后才展示首件填写入口；普通工序的报工区域保持原用途。
- 首件支持合格、不合格、待确认结果、实际检验时间、检验人、照片和补充说明。首件结果不自动形成新的生产放行限制，也不重复计算报工数量或个人工时。
- 巡检从扫码检验入口移除。品质在质量数据中按日、周、月、自定义日期搜索归档，上传整份报表；报表归档状态不代表其覆盖产品全部合格。
- 照片及 PDF 使用现有对象存储和预览器，支持预览、缩放、旋转、保存阅读方向、全屏、原件下载；照片可以调整顺序。上传队列支持多选、移除、排序和失败后继续，表单防止未保存内容被意外关闭。
- 已提交记录的修改需要原因，保留版本与操作历史；作废进入回收站并可恢复。原始文件不被旋转操作覆盖。保持现有质量数据权限和登录要求。
- Prisma 迁移允许巡检不绑定工单，为首件增加工序快照，为附件增加排序。旧首件记录不猜测工序，保留在“历史未指定工序”；历史巡检及在线表单数据保留。工序快照不增加阻碍路线退役的外键。
- Excel 包含纸质记录摘要和首件工序信息；附件 ZIP 按记录和照片顺序导出。巡检日期统计使用上海业务日期，避免 UTC 跨日混组。

发布验收包含单元测试、真实 PostgreSQL 集成、S3 上传下载、首件工序隔离、巡检日期归档、版本冲突、旋转持久化、Excel/ZIP、作废恢复、平板和手机交互。发布流水线对源镜像与杭州匿名拉取镜像分别运行质量数据及纸质检验接口验收。

本次交付镜像，不直接切换 Sealos 正式应用。应用部署时由现有启动程序执行 Prisma 迁移。

# v1.34.137 — 报工撤回、部分核销与整单完结

本版本基于 v1.34.136 首页版本，修复成品数量满数但仍有工序待核销时，撤回报工把整单错误关闭的问题。已完成且全部有效工序闭环的历史工单继续保留原完成时间。

## 修复行为

- 报工、撤回、工序发布使用共同的工序状态核对。满成品数量允许保持生产中；数量校验不再把这种合法状态视为冲突。
- 撤回后整单保持打开，并清除完成时间。原报工核销状态参与工序判定，避免仅按局部到料805等于已处理805就判整道完成。
- 工序发布和核销恢复即使没有新增成品，也会同步主单状态，避免补充义务未完时残留已完成。
- 历史恢复增加部分核销场景。要求有效成品流水达到目标、历史删除承接审计、该道原物料流与已核销记录一致，且无半成品、分支、不良、动作单位歧义；不足证据不会自动补数量。
- 有充分证据的旧工序转为独立实际工作量义务。保留原物料流水和工时，原805物料投影留入审计快照；活动投影不再输出第二份物料。只补齐既有报工尚未核销的差额，不重复分配805，也不新建报工或重复计工。原未报/已撤回的400仍需按实际作业报工。
- 恢复结果推送具备工艺处理权限的有效账号，链接到相应工单流程；原报工待处理账号通知、实际恢复后完成待办及无需必填说明的规则继续保留。
- 原错误完成记录恢复生产中后，原周遗留承接可重新激活；当前执行列表明确标注包含子单，顶部概览计数范围给出解释。

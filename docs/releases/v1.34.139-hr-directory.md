# v1.34.139 — employee directory workspace

Employee account management previously occupied a separate row above a full-height HR view. Combined with clipped overflow, this could push profile actions below the viewport. The new bounded layout places account management in the directory command bar and reserves a footer row for editing and creation.

The directory now uses an orange, light-surface visual system; compact employee metrics; a collapsible organization filter; an employee list; readable profile fields; and an on-demand position/account drawer. Organization, position, team and attendance grouping are edited in Appointment. Account permissions and employment/attendance business rules continue to use their existing APIs.

Editing and creation have persistent Cancel/Save controls and visible server errors. Invalid fields receive focus. Internal employee/view changes, refresh, cancel and browser history preserve unsaved changes through an accessible confirmation dialog. Repeated save requests are guarded; successful creation keeps the new employee selected and updates the URL, list and profile.

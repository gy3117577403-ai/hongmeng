# v1.34.198 计划资料审核与治具准备修订

新规则固定适用于 2026-09-21 起的新计划批次。已存在工单按迁移时的原始计划范围记录，后续跨周调整不改变其规则。历史产品用于新的生效计划时，需要审核本次适用资料。

- 首页采购、资料与治具改为标题栏入口和玻璃浮层；计划状态缩为紧凑行，并提供两级审核及治具筛选。
- 图纸资料库是产品资料及是否需要治具的统一入口。计划导入带出已有选择，允许选择行批量设为无需治具。无需治具不填理由，不开放 BOM。
- 已上传的生效计划通过持久队列自动接入图纸和 SOP。完整资料进入主管初审，主管通过后送质量复审；不足项进入待完善。审批与上传、两级审批人员分离。
- 图纸、SOP、BOM 及治具要求变更保留版本履历，未绑定的新工单在异步同步窗口内也不能借用旧批准。首个打印记录锁定批准版本；版本停用仍沿用既有明确沿用范围机制。
- 治具准备只显示生效的有效计划且明确需要治具的产品，支持计划周和缺 BOM、待匹配、数量不足、在途、齐套筛选。无需治具仍需审核图纸和 SOP。
- 治具不足、尚未匹配和采购在途均不额外阻止已审工单打印。正式打印仍检查原有工艺及可打印文件规则。
- 连接器登记只需连接器型号、对插型号，可选初始数量；编辑与删除保留历史，共享对插库存唯一。数量调整具有并发检查和流水。
- 治具专用采购独立于普通采购，分批收货回写治具库，在途数量跨同产品的资料修订合并计算。采购消息继续使用“杭连采购”。
- 新工作台仅保留资料审核、治具准备、治具库、库存记录；移除重复档案页和独立生产提示页，生产工单直接显示实际版本、审核和治具状态。

## 升级与启用

无需新增环境变量，沿用数据库、对象存储、登录配置和已配置的采购推送。容器启动执行 Prisma migration；后台在数据库队列中接入生效计划，不自动批准。

在“审核设置”确认主管初审、质量复审人员；已配置的名单保留。原图纸资料库使用“生效计划：治具未选择”筛选补选历史已导入的下周产品，然后在资料审核补齐缺项。

本版本镜像交付不代表已切换 Sealos。所有操作验收使用独立测试数据库，不修改正式采购或发送真实群通知。

## 验证

类型检查、生产构建、单元测试和 PostgreSQL 集成回归；浏览器验证首页浮层、计划筛选、资料预览与连接器增改删及数量调整。HTTP 验证真实 Excel BOM 上传识别、主管和质量两级审批、审批前拒绝打印、缺具时允许打印、图纸与 SOP PDF 下载、治具采购分批入库和普通/治具采购隔离。最终镜像身份与干净运行环境验收单独生成证据。

# v1.34.150 员工调岗与达成口径修正

员工由样品组调入量产后，仅修改当前部门、班组或档案分账，旧考勤中的样品快照仍可能让报表显示“不参与达成”。本版增加按工作日期生效的调岗口径，修正旧考勤，并让之后的补录、确认和报表采用同一日期规则。

## 办理与历史修正

进入 **人事与工时 → 员工档案 → 编辑 → 任职信息**。调入量产时核对班组、考勤分组，并把“统计分账”设为“批量生产”，填写生效日期及原因。保存会先列出受影响的考勤、已确认天数、其他工时及保留的单日例外；确认后在一个数据库事务内保存。

如果当前档案已经正确，点击 **修正已生成考勤的达成口径**，直接按生效日期补正历史记录。沈静（0011）本次由用户确认从八月起参与量产，办理时使用 **2026-08-01**。此版本交付的是应用修复与镜像，不会在未切换版本时自动修改现有 Sealos 数据，也没有把某位员工姓名写进通用数据库迁移。

- 生效日前已有记录保留，生效日起同步旧快照；出勤、加班、报工、损耗、批准时长和原确认状态不变。
- 第一次建立历史政策时，如生效前存在已确认且非单日例外的考勤，以最近一条的快照作为早期缺失日期的补录依据，并在预览中展示来源。没有历史依据时保留当时档案基线。
- 单日临时借调通过考勤编辑中的“仅当天单独设置（临时借调）”登记，必须填写原因。解除勾选恢复该工作日期的有效档案口径。
- 显式标记的单日例外不被整段调岗覆盖。旧版未记录“单日例外”标记的记录不能凭空识别，办理前应核对预览。
- 后续再次调岗不会改动更早时期。已经存在后续调岗时，不允许直接插入更早的整段变更；较早个别日期通过单日修正处理。
- 预览与提交间如资料变化，会要求重新预览。相同请求可安全重试，员工事务锁和版本校验防止重复处理。
- 其他工时的审批状态与批准时长保持不变；统计快照及班组同步，待审批通知按新班组重新分配，审计轨迹标记“调岗口径同步”。

## 报表与公式

日、周、月、个人矩阵使用日期对应的同一口径，周期先合计参与达成日期的分子与目标工时再相除。每日抽屉与 Excel 的“每日工时明细”显示统计分账及口径来源，导出班组取当天快照。

```
达成率 = (完成工时 + 已确认损耗工时 + 已批准其他工时)
         ÷ (实际出勤工时 × 0.95) × 100%
实际出勤工时 = 正常出勤 + 已确认实际加班
```

截图数字的隔离复现：完成 7.31h、损耗 0.5h、其他 0h、正常出勤 8h、加班 2.5h，参与量产后得到 **78.3%**。缺少应登记考勤时仍显示“—”，防止用不完整分母算出虚高达成率。

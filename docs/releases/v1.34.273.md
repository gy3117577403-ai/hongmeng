# v1.34.273 — 采购与物料三项改进最终交付

基于 v1.34.272（`3f001c32fc640a8c7d175a09405deda54181d783`），包含到料结果核对、采购资料后补、直观数量显示及历史计量更正；同时保留 v1.34.271 的缺料与来源交叉筛选、已采购和待采购分类、财务采购明细 Excel 导出。完整业务说明见 [v1.34.272](./v1.34.272.md)。

## 最终截图复核修正

390 像素宽度下，物料工作台的通用下拉框旧样式将「本次到料后，本项是否全部补齐」限制为 130 像素，完整选项文字显示不全。本版解除该控件的最大宽度限制，使其填满提示区域，并增加实际浏览器宽度检查。

新增浏览器流程共 20 项断言，覆盖采购资料留空、收货后补充、原始收货与资金快照保留、历史计量核对、仓库采购状态一致及小屏完整显示；原采购分类与财务导出另有 10 项断言。发布流水线对正式镜像及匿名杭州镜像分别运行这些验收。

## 数据库与交付

本版没有新增迁移。从 v1.34.271 升级时，仍需由镜像既有启动流程执行 v1.34.272 的两项迁移：`202610150002_material_arrival_outcome` 和 `202610150003_purchasing_quantity_units`。迁移不会自动关闭历史缺料或改写实际采购数量与金额。

交付杭州镜像；生产环境切换及历史业务记录核对不由发布脚本执行。最终镜像摘要和运行验收结果以 v1.34.273 标签流水线为准。

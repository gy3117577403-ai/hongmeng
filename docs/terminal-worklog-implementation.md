# 端子调模作业与刀片库存

本次基线 v1.34.249；新增内容独立于样品、仓库、订单池的待提交变更。

## 验收范围
- 整套型号为主，四刀位散刀、整套实物、盒位 001–100、移位/归还/盘点和库存流水。
- 手机扫码登录留在手机工作台，模糊搜索端子，新增型号不被资料完整度阻断。
- 整套带入四刀位，允许混搭；本次组合保存快照，正式方案单独发布。
- 开始/暂停/继续/完成/未完成记录；刷新和重开恢复进行中作业；防重复提交。
- 完成后分别选择归位、换盒、留在设备；未归还不冒充在库。
- 协助计时和补报，同一员工仅一项进行中；跨日拆分，接入其他工时事实台账。
- 电脑作业记录、刀片库存、端子方案、日周月统计与导出；固定操作区、内部滚动。
- 已登记库存不得负数或重复占用；未知数量显示待盘点；重试幂等、并发验证。
- 普通协同和只读账号验证，手机端入口/API 权限一致；权限不足保留目标而不跳桌面。
- 目标尺寸：1366×1024、390×844；验证真实列表、编辑、计时、完成、返回。
- 构建版本 v1.34.252，发布不可变镜像并验收，交付杭州完整地址；不执行 Sealos 切换。

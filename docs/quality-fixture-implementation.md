# 导通治具与生产资料审核

当前规则：资料审核和治具准备独立管理。镜像发布与正式环境切换分别验收。

## 固定规则

- 需要/无需治具归属产品；无需不填原因、不能上传适用 BOM。改变治具选择保留现有图纸 / SOP 审核结果。
- Excel xlsx/xls，表头映射、人工确认、来源行和修改原因可追溯。
- 图纸或 SOP 至少一种即可送审。主管、品质顺序不限，双方均通过才可打印；管理员默认可分别完成两项，普通审核人仍不能自审上传或提交的生产资料。
- 正式工单单打、批打、补打、打印包及确认统一校验资料审批。
- BOM 缺失、待确认、未匹配、缺具、在途、未预留不影响送审、审核或打印。未确认 BOM 的治具需求标记为尚未计算，不算齐套。
- QfPreparation 独立保存当前 BOM、数量口径和准备版本，QfEvent 保存准备履历；后补或更新 BOM 不修改 QfPackage、审核签名、打印快照。历史资料指纹保留。
- 治具申购来源固定、资金与统计分开；库存只有 PcStockBalance/PcStockMovement 一套事实。
- 空闲可用=在库-待验证/隔离-维修-预留；在途不算现货。
- 文件入 S3，元数据入 PostgreSQL，软删除；关键事务版本检查及幂等。

## 开发与验收顺序

1. Prisma schema/migration，BOM 解析与校验，资料版本/两级审核。
2. 治具对应关系、共享库存、预留/借还/维修、采购来源/验收入库。
3. 服务端全部打印通路，生产/计划/图纸库集成与完整工作台。
4. 单元/数据库/HTTP/浏览器验收，镜像发布、杭州完整拉取与空库启动。

实际 BOM 模板和审核人由正式界面配置；不预置真实审批结果、库存或群消息。

## 使用入口与上线配置

首页新增「资料与治具」快捷入口；质量菜单进入完整工作台。计划中心、图纸资料库和生产执行的资料状态均可跳转到对应产品。

1. 「审核设置」指定主管、品质人员。管理员默认可分别签署两项；普通人员两项需不同账号，图纸 / SOP 上传人与资料提交人不能自审。单独上传 BOM 不影响图纸审核权限。
2. 上传或选择图纸 / SOP，选择是否需要治具，即可提交资料审核。需要治具的产品同时进入治具准备，可随时补充 Excel BOM 并确认表头、连接器行和数量，无需先完成治具库建设。
3. 治具匹配与申购中确认完整对插型号及依据。治具库也可直接补充申购，采购记录来源固定为「治具申购」。
4. 采购端验收后自动记入同一治具库存。待组装、待验证库存通过对插和导通验证后转可用。
5. 主管和品质均通过才可打印。实际图纸 / SOP 修改后需重新审核。新版待审时保留旧版批准结果；计划可指定适用资料版本。旧版被替代后，品质可为指定在制工单设置沿用范围。

无需新增数据库、存储或治具模块环境变量，沿用现有 PostgreSQL、S3 和 SESSION_SECRET。采购消息沿用采购模块的 PURCHASING_WECOM_WEBHOOK_URL / APP_BASE_URL 或界面中的加密配置，统一以「杭连采购」开头，并注明治具申购来源。

新增迁移由镜像启动时自动执行，从现有资料版本复制治具准备数据，原审核记录和打印快照不变。审核范围固定为 2026-09-21 起的生效计划，之前的计划按既有规则处理。迁移不会自动批准、生成库存或补发申购；原有报工不增加审核阻断。

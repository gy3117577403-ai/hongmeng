# 质量数据与端子参考库 V2 · v1.34.123

## 页面与扫码

质量数据只保留一处标题，顶部分为“检验记录”和“参考数据”。检验页使用紧凑筛选、可点击状态统计以及订单 / 记录 / 详情三栏；无数据时合并空白面板，直接提供五类新增入口。更多筛选和追溯字段按需展开，适配 1366×1024 平板及手机，使用橙色玻璃层次与轻量按压反馈。

复用现有生产二维码。普通员工直接进入原生产报工；只有质量权限的账号直接进入质量登记；同时具备报工与质量权限的管理员、组长、调模兼岗先选择入口，并可在页面顶部互相切换。未绑定员工的管理员可登记质量；生产报工仍执行原有员工身份规则。调模需已有“质量数据填报（调模兼岗）”授权，不向工艺部门全员自动开放。

## 精简登记

工单批次由扫码或左侧选择确定，自动带入标题、当前时间和当前检验人。工序只有唯一选项时默认选取。班组复用系统已有班组；明确匹配到一个所属班组时默认选中，也可搜索选择。保存班组稳定 ID 与当时名称，后续改名或停用不改变历史记录。

在线填写只需一项真实检查内容，或上传实际检验附件。文件归档只需附件，摘要选填；新记录可从文件名生成标题。时间、人员可修改，数量、标准、设备、端子、线材和追溯信息按需补充。未填写有效标准的数值保持“待判定”，文件不会自动判合格。下一样本沿用项目结构但清空实测值。支持手机拍照、文件上传、草稿、提交、修订、复核、回收站及恢复。

## 独立参考数据

当前仅开放端子压接参考方案，独立保存，不关联工单、产品或检验结果。端子可复用现有端子目录，也可输入厂内型号。每个型号可维护多套适用条件不同的方案。

- 压接尺寸：导体压接高度、绝缘压接高度、压接宽度等，数值、公差、单位分别记录。
- 机器设定：高度调节刻度、送料长度、速度等，必须注明适用机台，避免将刻度误当成实际尺寸。
- 适用条件：线材说明、mm² / AWG、绝缘或并线情况、机台、模具 / 工装。
- 来源：经验记录、依据文件、已验证。标记已验证须填验证人、时间和依据；参数或适用条件变化时清除沿用的旧验证标记，历史版本仍保留原事实。再次验证需登记新的验证时间。
- 状态：草稿、在用、停用。在用方案须补充线材条件；修改在用或停用方案须说明原因。

支持新增、编辑、复制、个人收藏、关键字与端子 / 状态筛选、版本历史及差异查看、照片 / PDF / Excel 附件、Excel 与附件打包、软删除与恢复。复制产生新草稿并清空原验证身份。质量人员和管理员管理所有方案；组长和调模可查看全部授权数据并编辑 / 删除本人方案，恢复由质量人员或管理员执行。普通员工不能通过页面或接口访问。

检验表中的“查看参考数据”只供查询，不自动将机器参数或经验值写成实测数据、检验标准或合格结论。每套方案最多 80 个参数、30 个附件，每个文件最多 20 MB；导出最多 5,000 套，附件包最多 500 个文件 / 200 MB。

## 数据与验收

新增四张参考库表，由 Prisma 迁移创建。元数据保存在 PostgreSQL，附件保存在 S3 兼容对象存储。编辑使用版本校验，创建使用幂等标识，删除保留历史和原附件。

专项验收覆盖最简填写、班组历史、参考条件与验证、多人修改冲突、角色权限及撤权、附件内容一致性、导出、回收站和版本历史。发布工作流在构建后的正式镜像与匿名拉取的国内镜像各运行一轮真实 HTTP 检查，使用独立临时 PostgreSQL / MinIO。镜像发布与 Sealos 正式实例切换分别执行。

范围：计划准备、仓库配料、缺料跟进、生产准入、工序完成、工时领取、考勤达成率和登录保护。

边界：本轮不连接目标数据库，不访问或修改 Sealos，不提交生产工单、仓库任务、缺料反馈、工时领取或考勤记录。

## 固定合同测试

运行：

```powershell
npm run test:operations-flow
```

该测试用一条确定性的 1,000 套 A 产品场景串联以下规则：

1. 图纸和工艺已准备，但仓库待配料时，计划不能进入生产；
2. 仓库登记缺料后，计划显示物料异常并进入缺料跟进范围；
3. 缺料反馈依次经过接收、等待物料和待仓库确认；
4. 仓库复核并完成配料后，计划才达到生产准入条件；
5. 当前工序完成 1,000 套后形成 1,000 套可领取工时；
6. A 员工领取 800 套、B 员工领取 200 套后，数量和标准工时全部守恒；
7. 当日确认 8 小时出勤后，达成率容量按照有效出勤的 95% 计算。

该测试已加入：

```powershell
npm run test:production-closure
npm run verify:production-closure
```

因此以后修改计划、仓库、缺料、生产、工时或考勤任一模块，都会重新检查整条业务合同。

## 无数据库浏览器验收

使用本地生产构建和 Playwright CLI，只访问未登录入口，不填写密码、不提交登录：

1. 访问 `/home`；
2. 确认重定向为 `/login?next=%2Fhome`；
3. 确认页面标题和主标题均为“杭连协同平台”；

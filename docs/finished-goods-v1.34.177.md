# 成品仓 v1.34.177 交付

包含 [成品仓界面及启用规则](finished-goods-v1.34.176/README.md) 的全部实现：规格独立窄列、24 行紧凑作业、可编辑数量与运单、独立收发时间、批次和连续处理，以及旧结余一次性默认历史已出。

v1.34.176 的两次发布尝试均停在测试环境下载 MinIO 的阶段，Quay 返回 HTTP 502；没有发布应用镜像。v1.34.177 在昂贵的业务检查之前准备这项依赖，对下载作有限重试，并提供经过完整匿名下载及 SHA-256 校验的备用来源。两个来源固定使用同一个 Linux/amd64 清单 `sha256:a1a8bd4ac40ad7881a245bab97323e18f971e4d4cba2c2007ec1bedd21cbaba2`，即原上游索引的 amd64 内容。

应用的所有运行验收仍然完整执行。发布流水线将应用镜像推送到 GHCR，随后复制到杭州仓库并检查摘要一致、匿名拉取、空 PostgreSQL/对象存储启动与真实业务流程。v1.34.176 标签保留用于追溯，不覆盖或移动。

UI 与库存验收见根目录 [design-qa.md](../design-qa.md)。正式环境的首次启用才建立历史分界；本次交付不切换 Sealos。

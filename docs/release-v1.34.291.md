# v1.34.291 采购退款、合同模板与到料数量选填

基于最新成功发布的 v1.34.289，保留既有其他工时批量审批、加载优化及账号权限行为。本版本交付杭州镜像，不执行 Sealos 生产切换。

## 本次变更

- 票据 / 退款列表、批量选择栏及资金单关联采购新增退款到账入口。沿用财务职责授权，支持分次到账、个人收到后归还公司，并保存收款对象、账户、日期、流水号、备注和凭证。显示供应商未退、个人待归还及公司已收三个金额，保留原始付款、入库、退货和发票事实。
- 多账户请款移除编号分组及重复大表单，采用一张紧凑明细表、统一选填信息和一次提交。后台继续按供应商、收款账户、结算方式和账期分别生成资金单；整批校验和事务回滚保留，可减少本次申请金额。
- 通用合同模板以“杭州杭连电子有限公司”为需方，在线编辑主体、付款、税率、交付、验收、质保、退款、争议及特别约定，条款可增删调整。模板保存追加新版本；单份合同草稿、定稿和修订独立留档，历史合同不随模板更新改写。采购登记自动生成的合同也使用完整模板，未补齐内容保存为草稿。正式金额由采购明细在服务端计算，预估明细不允许直接定稿。支持可搜索、多页中文 PDF、Excel 下载及打印。
- 仓库确认到料保留数量输入但改为选填。留空保存“数量待补录”，不作为零件数、可用库存或产品配套数量；已有发货/报到数量保留为原登记数量。补录沿用原批次，少到、异常、重复提交和并发版本校验继续受控；仅有明确的原发货事实时继续保留未到余量在途记录。

## 数据变更与兼容

迁移 `202611090001_purchasing_contracts_optional_arrival` 增加合同模板版本表、合同正文/版本/状态、退款收款资料及数量待补录状态。历史数据不批量重写，历史简版合同仍按原快照展示和下载。历史退款中未记录的收款资料明确显示未填写。

既有采购审批、付款、入库、票据红冲、工时核算和生产统计的计算口径不变。新接口仍要求登录及既有模块权限；模板编辑仅向采购配置维护人/管理员开放，单份合同保存沿用采购经办职责，退款沿用财务确认职责。

该迁移允许到料批次数量为空。投入使用后若已有数量待补录记录，不应直接退回旧镜像处理新数据；需要回滚时，应在停止写入后按经过验证的升级前数据库备份恢复配套版本。

## 本地验证

- 普通测试：1,423 通过，0 失败；243 项条件集成测试按仓库规则跳过。
- 隔离 PostgreSQL 采购与到料相关测试：36 项通过，覆盖退款、金额更正、批量请款、个人报销、财务导出、数量选填和核验。
- 合同补充检查覆盖人民币大写、税额分拆、非法字段/日期、长明细多页导出、合同金额不可伪造、模板权限与版本冲突、定稿和修订历史保留；自动合同入口修改后相应合同与采购生命周期测试 10 项通过。
- 1366×1024 浏览器 29 项检查通过，实际完成退款、归还公司、紧凑请款、模板修改、自动合同草稿、合同定稿和修订、数量留空与原批次补录。实际下载 PDF 和 Excel，核对文件内容；PDF 两页均已渲染检查，中文、表格、页码及签章区完整。
- 类型检查和生产构建通过。保留仓库既有非阻断 lint 提示。未进行实体平板实测、全系统人工巡检或压力测试。

## 镜像验收

v1.34.290 首次镜像验收发现旧物料浏览器脚本精确匹配原数量标签，未兼容新增的“（选填）”提示，导致查找超时。v1.34.291 仅修正该脚本定位并更新版本号；旧标签保留。修正后原物料、仓库配齐及周计划协同浏览器流程本地通过。

发布流水线将对固定源码镜像及杭州匿名拉取镜像分别启动隔离 PostgreSQL / MinIO，执行既有发布检查及新增四项功能浏览器验收。最终提交、工作流、摘要和验收结果在发布成功后补充；此处不将本地测试视为镜像发布完成。

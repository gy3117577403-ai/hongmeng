# v1.34.183 实时员工工时达成率

三张卡片分别展示周计划项、实际成品数量和员工实时工时，点击可核对各自公式与明细。

- 员工工时：生产报工（含半成品与待匹配）、异常工时、其他工时。成功提交即按原工作日期计入；草稿、撤销、驳回不计入。核对或匹配后只调整差额。
- 达成率：同一人员和日期范围的计入工时合计 ÷（正常出勤与加班合计 × 95%）。缺勤数据保留已报工时；只有明确排班目标时显示预估。
- 生产工序效率分析标记不再扣减员工综合工时。多人标准工时按原工时分配结果汇总，缺标准且无明确申报时长的记录显示待补工时。
- 周计划与数量共用实际 FINISHED_GOOD 数量事实。半成品转仓只调整当前计划范围，不生成成品完成量；明细显示原计划、转出和接入数量。

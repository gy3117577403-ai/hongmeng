# 手机样品库 · 第一期

本期新增 `/sample-library` 手机专用只读入口，复用现有样品照片、数据与提交快照。无需重新上传历史资料。

## 员工使用

1. 在首页样品任务或计划中心的样品页点击“样品库二维码”，保存并张贴工作区二维码。
2. 手机扫码，使用员工账号登录；未登录时仍保留扫码目标，登录后继续打开。
3. 输入部分型号，也可用空格分开几个型号片段；点击“全部客户”筛选客户。
4. 产品详情提供照片、参数、工序工时、历次记录。点开照片可双指缩放、双击放大、拖动、旋转和切换。
5. 返回列表保留型号、客户、已加载页数和滚动位置。采集页面点击“参考历次样品资料”会打开覆盖面板，返回后保留尚未提交的输入。
6. 产品详情可生成该产品的固定二维码；后续增加样品记录不需要换码。

## 开通手机查看权限

系统管理员在人事的“账号与访问管理”中选择员工，进入“登录与安全”，勾选“手机样品库 · 只读”并保存。该权限独立于后台工作台、扫码报工；可只开通手机样品库。

已有生产与计划或技术与资料模块查看权限的员工，以及现有具备相关查看能力的账号，也可查看样品库。新增独立权限不会替换旧账号已有业务授权。账号停用、权限撤销后，现有会话失效。只有报工密码的账号开通浏览访问时，需要管理员配置独立登录密码。

## 数据口径

- 以现有图纸资料库产品 ID 归集，客户不同的同名型号不合并。
- 纳入真实业务中的历史已完成、已归档样品；无照片、无数据的空计划不当作参考档案。
- 排除测试、培训以及软删除的任务、产品和照片。
- 优先展示已有内容的已审核版本；新的空计划或未审核记录不会覆盖旧的已审核参考。
- 一次选择对应一个样品任务与提交版本，照片和参数一起切换。已提交参数从审核快照读取，后续编辑不改写历史显示。
- 未审核记录有明确标识；退回、撤回、作废和取消任务放在折叠历史中。
- 未提交分区仅展示实际填写的行；系统自动生成的空行不计为有效数据。
- 列表每次 12 个产品，照片先读取缩略图，点开后再加载原图；不复制照片到本地永久存储。
- 最近查看仅保存在当前设备，按员工账号隔离；服务端始终校验权限。二维码是页面入口，不是匿名文件下载凭证。

## 部署与验收

新增 Prisma 迁移 `20260924090000_sample_library_access` 为现有数据库权限枚举添加一个值，不重写现有样品数据。沿用应用已有迁移部署流程。

自动化验收使用独立 PostgreSQL、MinIO 和专用测试账号；不在生产库写验收样品。验收覆盖模糊搜索、客户隔离、历史快照、权限撤销、缩略图、手机尺寸、照片手势以及原位置返回。镜像验收和线上切换是两个独立步骤。

本期需要联网；不包含离线资料包、微信小程序或原生 App。浏览器手机尺寸与触摸模拟可自动验证，真实手机及微信内置浏览器的扫码与兼容性仍需在目标部署地址验证。

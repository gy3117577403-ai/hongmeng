# v1.34.185 — 达成率总览新增生产工时与人员能力

原来的周计划达成率、成品数量达成率和员工实时工时达成率继续保留。新增卡片位于同一个达成率总览内，支持打开计划、剩余工序、人员范围、能力测算明细。

## 计算口径

- 本周计划工时达成率：本周计划及本周半成品接续的已报标准工时 / 当前周任务标准工时基准。按工序封顶，待匹配报工立即计入；匹配后不重复增加。
- 当前待做总工时：本周计划剩余 + 已纳入本周的遗留任务剩余。周前完成工序扣除，转仓、改排移出明确展示，原工单和半成品接续之间只保留一份工时归属。
- 全部任务推进率：本周累计完成 / 本周任务总基准，不能以持续减少的剩余工时当成完成率分母。
- 本周预计人员能力：正常量产生产人员每人 6 天 × 8 小时。排除样品、组长、主管和档案排除人员；入职、离职、调岗按生效日期计算。独立于考勤，不使用 95% 系数。
- 两项整周覆盖参考：整周预计人员能力分别除以本周计划总工时和当前待做工时。另显示剩余正常班次能力、覆盖率、缺口或余量，周一至周六 08:00–12:00、13:00–17:00，北京时间。
- 异常和其他工时保留在员工实时工时中，不作为已完成产品工序。缺标准工序显示已知合计及补齐提示，避免虚假达成率。
- 只读新接口使用既有登录与生产数据范围；同一数据库快照读取待匹配及已匹配报工。每 30 秒、页面重新激活、工时报送事件刷新。

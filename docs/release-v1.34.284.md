# v1.34.284 采购跨页选择、入库标识与样品配料

基于已发布的 v1.34.283。发布源码提交：`ba98a79b9249f6038785f54e549fcd50a7c5b594`。

## 跨页请款与报销

- 表头复选框仅添加或取消当前页；翻页保留其他页的选择。翻页时同步锁定复选框，避免在旧页数据上操作。
- 增加“选择全部筛选结果”、跨页已选明细、总金额与可申请金额。单批最多 100 项，超限明确提示，保留原选择。
- 改变搜索、业务队列或筛选范围会清空原选择；取消选择会阻止旧的异步全选结果恢复。
- 未登记采购、余额已占用、金额更正待复核、退款未结清或无申请权限的记录显示原因，可一键仅保留可申请项。
- 提交前重新读取状态、版本与余额。不同收款人、账户、币种、业务来源、结算方式或账期按现有资金规则分组，每组生成独立资金单。
- 分组批量申请按各项可申请余额办理；部分请款继续在单组资金申请中处理。任一组校验失败整批回滚，重复提交使用原有幂等保护。
- 导出选中记录覆盖跨页明细；记录变动导致结果不完整时明确报错。

## 采购入库状态

- 列表增加醒目的文字与颜色：绿色“已入库”、橙色“部分入库”、灰色“未入库”，另有“未采购”和“已取消”。
- 根据累计收货数量、原采购数量及取消待收数量计算，显示已入库/应收、待收数量；退货数量单独展示。
- 入库状态不使用付款状态或当前剩余库存推断。已入库后领用或退货不会抹去收货历史。
- 入库状态支持筛选；采购明细导出增加“入库状态”和“待收数量”。已取消记录不再显示待收数量。

## 样品配料权限

- 原仓库配料页面使用了样品计划接口，导致已有仓库协作权限、没有样品计划权限的账号无法读取列表。
- 列表、周数量、详情和配料操作改用仓库命名空间下的专用接口，沿用已有仓库权限。
- 仓库协作账号可查看并确认配齐；仓库只读账号可查看，不能修改。仓库权限不授予样品计划编辑能力。
- 无权限或读取失败时展示明确错误与重试入口，不再伪装成“没有配料任务”。
- 没有修改生产账号授权或生产配料记录；使用与金丹权限范围相同的隔离账号完成操作验收。

# v1.34.202 — 资料审核与治具准备独立运行

需要治具但没有 BOM、BOM 待确认、对插未匹配或数量不足时，图纸 / SOP 可以照常提交审核。主管与品质顺序不限、双方均通过后可按原打印流程生成工单与已有的受审文件。管理员仍可分别完成两项签名。

## 操作变化

- “编辑资料”管理图纸 / SOP；“BOM 与治具准备”独立保存、识别和确认连接器。
- 后补、更换或确认 BOM、调整同时测试数量、更改治具选择均不清除资料签名、不增加图纸审核版本。
- BOM 尚未确认时显示“需求尚未计算”，不显示齐套；确认后再计算匹配、缺口和采购在途。
- 未完成的 BOM 编辑可以暂存；版本冲突要求刷新后再保存，防止覆盖他人的准备结果。
- 准备履历保留当时的 BOM、操作人和准备版本；图纸审核履历保持独立。
- 治具专用申购沿用“杭连采购”，与普通采购分开；采购记录保留准备依据，在途抵扣及收货库存继续共用既有台账。

## 数据与上线

新增迁移 `20260920110000_independent_fixture_preparation` 创建 `QfPreparation`，从最新产品资料复制准备数据。原资料版本、签名、历史指纹、采购和打印引用不改写。文件继续存储在 S3，元数据存储在 PostgreSQL。

无需新增环境变量。范围仍为 2026-09-21 起纳入审核的计划；历史计划政策不变。实际图纸 / SOP 变更、资料退回或撤销仍执行原有审核和打印限制。

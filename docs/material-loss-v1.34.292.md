# 样品配料和物料损耗

基于最新成功发布的 v1.34.291 开发。功能范围为样品到料与配齐、日期显示、物料损耗台账和独立账号权限。运行时继续使用现有 PostgreSQL、S3 和会话配置，无新增必填环境变量。

## 样品配料

样品缺料行可直接打开共用的到料核验弹窗；顶部“核对缺料后确认配齐”可在样品页面内处理，不必跳转物料跟进。数量留空记录为待补录，后续在原批次补数量，不编造零数量或重复到料。少料、异常、在途和整单配齐继续使用既有服务端校验。

配齐导致任务离开当前“缺料”筛选时，右侧保留本次处理的任务供核对；用户重新筛选、翻页或选择其他任务后回到正常列表行为。

日期按上海日历显示。客户字段误存日期的历史记录显示“客户待核对（原值 YYYY-MM-DD）”，不猜测或批量改写客户名称；新增样品导入会拒绝日期格式的客户字段。

## 账号权限

在“员工与账号 → 账号管理 → 账号与访问管理”的小模块权限中分别配置：

- **物料损耗申报：协同**，可申报、编辑本人草稿、提交/撤回、发起更正和登记本人补料进展。
- **物料损耗审批：协同**，可审批或退回其他人员的待审批记录；不能审批本人申报。
- 两项均支持只读，不授予对应写入动作；默认未开通，不从原物料大类或管理员身份自动继承。

保存其中一项不会隐式授予另一项或仓库权限。每次操作重新检查有效权限，直接调用 API 也受相同约束。提交时须存在其他有效审批人，否则保留草稿并提示配置账号。生产环境的具体人员权限由管理员配置，本次发布不修改正式人员权限。

## 损耗流程和统计

入口为“物料追踪 → 物料损耗”，亦可从关联样品配料打开。支持量产、样品、订单池任务或仓库公共损耗。每单记录一个物料，填写名称、规格、单位、采购/客供来源、数量、发生日期、原因分类和具体原因，可附图片/PDF，并选择是否影响配齐、是否补料及补料数量。

草稿 → 待审批 → 已通过/已退回；提交人可撤回。提交和处理结果保留站内通知及操作轨迹。审批、网络重试和并发操作有版本校验与幂等保护。

仅统计已通过且未被更正替代的记录，不同单位分别汇总。已通过内容不可覆盖编辑，须创建更正单，填写更正原因并再次审批；新更正生效前原记录仍有效。更正可调整损耗数量、日期、分类、原因及影响配齐标记，保留原关联物料、订单和补料安排，避免改写已发生的实物记录。

需要补料时，审批生成一个独立跟进任务，允许分次记录累计可用到料。完成须达到补料数量并明确核对实物；更正不重复生成补料任务。补料登记不自动创建采购单、付款或库存流水。

影响配齐的已批准损耗在仓库显示待实物复核提醒；仓库按现有到料确认权限登记核验说明，之后才允许新的整单配齐确认。已配齐的历史结论不会被损耗审批自动撤销。

**本模块不自动扣库存，不改变工时、达成率、采购金额或库存计算口径。** 附件存入对象存储，数据库仅存元数据；移除附件采用软删除。支持按筛选导出 CSV，最多 5000 条。

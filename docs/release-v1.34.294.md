# v1.34.294 样品配料与物料损耗

基于最新成功发布的 v1.34.291 开发。本次交付杭州镜像，不执行 Sealos 正式环境切换，也不修改正式人员权限。

## 业务变更

- 样品缺料行直接打开共用到料核验，顶部可在当前样品页面核对缺料后确认配齐；数量留空记录为待补录，补数量沿用原批次，保留少料、异常、在途、重复提交和并发校验。配齐后右侧保留当前任务供核对。
- 样品日期按上海日历显示。截图中的长英文日期来自客户字段误存日期，现显示“客户待核对（原值 YYYY-MM-DD）”；不猜测客户名称、不批量改写正式数据。新导入拒绝日期格式客户字段。
- 物料追踪增加物料损耗台账，支持原因、附件、关联订单/样品、申报、审批/退回、撤回、更正、操作轨迹、站内通知、筛选统计及 CSV 导出。数量保留六位小数，统计按单位分开，仅计当前有效的已批准记录。
- 账号权限独立增加“物料损耗申报”和“物料损耗审批”，均须单独开通“协同”才能执行对应动作，只读不可写入，不能审批本人申报。原物料大类或管理员身份不会自动授予新权限。
- 审批后可生成独立补料跟进任务，支持分次累计到料和实物核验。更正保留原补料安排与已发生事实。影响配齐的已批准损耗提示仓库登记实物复核，历史已配齐状态不会被自动撤销。

不自动扣库存，不自动生成采购或付款，不改变工时、达成率、采购及库存统计计算口径。附件保存在对象存储，数据库存元数据并保留软删除轨迹。

配置方式及流程限制见 [功能说明](material-loss-v1.34.292.md)。该说明文件名沿用初始功能候选版本，最终发布身份为 v1.34.294。

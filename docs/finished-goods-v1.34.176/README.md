# 成品仓 v1.34.176

本次按确认预览和后续补充调整成品仓：规格单独窄列显示，旧结余在新版首次启用时按约定默认历史已出，之后的生产完成流水正常转入待接收。

## 界面与操作

- 顶部简化为出货、库存、记录、批次；使用平台原有浅色导航。
- 主表取消序号、产品名称、承运商、逐行批次；工单显示短号，明细保留完整工单。规格固定 112 px，运单固定 156 px，右侧保留扩展空间。
- 默认每页 24 条。目标 1366 × 1024 下，普通和连续处理均可见 24 条完整记录。
- 数量及运单可直接输入、粘贴；Enter 保存信息，确认交接才产生实物出货。没有扫码器或摄像头接入，不展示扫码提示。
- 本轮批次可以选择和新建；实际发货使用本日批次，不受历史查询日期影响。更多操作支持对所选行应用批次。
- 连续处理支持数量、运单、收货信息、实物核对和“发货并下一条”。
- 列表显示首次入库时间与本次实际出货时间。入库记录逐次显示数量和时间；分配公共备货不重置入库时间。后补单号不改变出货时间。
- 支持库存留库、释放、部分发货、日期范围/全部日期查询、历史运单搜索、发货记录、批次、真实 Excel 导出和原有凭证/打印。

## 启用分界

新增迁移 `20260915090000_finished_goods_cutover`。迁移锁定生产来源和仓库表后记录一次数据库启用时间，结清所有已有仓库余额，并保留历史数量和结清流水。旧待执行草稿取消；原有真实已发单据、运单和 ShipmentEvent 保留原值。

“历史默认已出”不是补造实际出货：没有凭证的时间与运单留空，结清数量不计为当日实发。旧来源变更不重新恢复库存；同一个旧工单在启用后新增的有效生产完成流水仍会入仓。后续重启不会再次结清新库存。

此次镜像交付与 Sealos 正式切换分开；本次不更改正式环境运行镜像。

# v1.34.187 — 计划与执行工时口径对照

计划中心原来只展示计划单件工时乘以数量的合计，生产执行则以当前工序标准经过跨周、转仓和半成品接续调整后作为分母。同一批产品采用不同标准时，没有可见的差额解释。

本次在计划中心明确标注“原始计划工时”，保留批次/订单计划优先的现有取值规则，并增加同批次当前工序标准及差额明细。缺少保存计划而使用产品标准补算的批次明确标记，补算值不伪装为历史快照。

生产执行的达成率总览新增原始计划、当前工序标准、本周执行基准对照，保留原周计划达成率、成品数量达成率和员工工时入口。明细可逐批查看正负差额，并展开跨周扣减、已调整工序报工、转出、待补工序估算、半成品续作的分母计算。原始计划与当前标准差额只比较本周正常批次，不混入遗留或半成品续作。

缺计划或工序标准时不把未知量视为零，不显示确定的总差额；逐批正负差额相抵时仍提示有差异批次。本次不改写计划快照、报工记录和既有分母，不增加数据库迁移。

验证覆盖计划优先级、补算、未知标准、正负差额相抵、审计样例恒等式；真实 HTTP 场景覆盖原计划与工序不同、跨周报工、待匹配、转仓、半成品接续及原计划值保留。镜像发布后验证杭州镜像完整匿名读取和干净数据库启动。

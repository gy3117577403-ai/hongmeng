# 质量数据 V1

按订单明细、生产批次和稳定生产工单归档五类质量记录：端子压检、拉力测试、成品检验、首检、巡检。产品仅用于查询和历史快照，不共享不同订单的检测事实。

扫码复用原工单二维码。普通员工保持报工入口；组长、调模兼岗显示报工与质量入口；质量账号不需要报工授权。新模块独立授权，现有质量账号和组长自动获得对应能力，调模通过独立“质量数据填报”兼岗模板开通，避免将工艺部整体当作调模人员。

第一版包含手机/桌面表单、服务端草稿、幂等提交、附件归档、日/周/月/自定义检索、Excel、单份 PDF 和附件 ZIP、修订历史、复核、软删除与恢复。批次应检清单及提醒属于后续版本。工单完成和跨周不抹除质量历史；记录不直接改变产量、工时或生产放行。

检验标准由填写人按有效工艺填写并随记录冻结。未设置标准或未完成检查不自动判为合格。修改已提交记录必须说明原因；复核后的变更重置复核状态。附件不永久保存到应用本地磁盘。

验收覆盖账号权限和到期撤权、旧二维码入口、开工前首检及完工后复检、同型号不同订单隔离、并发版本冲突与幂等、所有筛选页导出、附件一致性、删除恢复和不可变历史。发布需完成 CI、镜像版本及 digest 验证、国内代理完整内容验证和独立数据库/对象存储启动验收；不自动切换正式部署。

## 使用方式

1. 从平台导航进入“质量数据”，左侧选订单 / 生产批次，点“新增记录”选择检验类型；也可扫描原生产工单二维码进入质量填报。
2. 在线表单记录检验工序、人员、班组、样本、位置 / 线号、标准、实测值、单位和异常说明。端子、线材批次、设备、模具和检验仪器可按需要补充。
3. 已有纸表或检测机导出文件可选“已有文件归档”，上传照片、PDF 或 Excel，并填写实际检验时间和摘要。文件本身不会自动被判定为合格。
4. 草稿保存到服务器，可关闭后继续编辑。提交后修订需说明原因；重新测试用“新增复检”，原记录保留。质量人员可复核、退回、作废和恢复。
5. 日期按北京时间计算；可按实际检验时间或系统录入时间筛选。关键词查订单、型号、人员、班组、工序、测量内容、摘要与附件名，不解析附件正文。
6. Excel 和附件打包覆盖所有筛选结果；单份记录与历史版本可下载 PDF。Excel 最多 5,000 份记录，附件包最多 500 个文件 / 200 MB，超过限制会提示缩小范围。每份记录最多 120 项测量、30 个附件，每个附件最多 20 MB。

## 授权

| 账号 | 可用范围 |
| --- | --- |
| 质量部门完整权限、质量审核权限、管理员 | 查询、填写、附件、导出、修订、复核、作废和恢复 |
| 车间组长 | 查询、填写、附件、导出、修订本人记录、删除本人草稿 |
| 调模兼岗 | 在账号中心明确添加“质量数据填报（调模兼岗）”，范围同上；原报工授权独立保留 |
| 普通员工、仅工艺专员等其他账号 | 无质量数据入口及接口权限 |

已提交记录、原始附件和人员 / 订单快照保留在修订历史中。作废是进入回收站，不物理删除文件；撤销账号授权会使旧会话失效。

## V1 验收记录

- 独立 PostgreSQL 16：134 个迁移可执行；新增质量数据表结构与 Prisma 定义一致。生命周期专项覆盖订单身份、复检保留原不合格、并发修改、软删除、历史快照及外键保护。
- 65 项真实 HTTP 检查：六类角色、五类表单、文件归档、二维码、撤权、原附件 SHA-256、Excel 和 ZIP 内容。
- 浏览器：1366×1024 平板和 390×844 手机；实际保存草稿、关闭重开、上传、提交、复核、查历史、作废、恢复、预览、下载 Excel / ZIP / 两页 PDF。PDF 下载文件逐页渲染检查，照片保持原比例。
- 发布工作流会在构建后的镜像和国内镜像分别执行质量数据 HTTP 验收，使用临时 PostgreSQL / MinIO，不使用正式业务数据。

# v1.34.298 误填不良数量更正与误建返工单作废

基于远端最新发布 v1.34.297（9e1ce780）及其交付记录 e4eabc1a 开发。

流程详情的有不良报工记录新增“质量数量更正”。先只读预览数量前后值、关联返工单、原工时领取及阻断条件；操作人确认真实劳动且仅质量分类误填、填写原因后才能提交。适用于动作计工记录将本笔误填不良全部恢复为良品，整套处理数量和动作报工总数不变。不是任意数量编辑，也不用于重复报工、报废补产、正式质检结论更改或按良品/整批计工的重算。

更正与误建返工单作废在串行化事务内一起完成。保留原报工、人员、工作日期、工时池和全部领取；更正前后逐笔校验全订单工时台账。空返工单标记 CANCELLED 并保留历史，不假报返工完成。分流冲销、动作来源补充和后续报工核销复用现有数量规则，不重新报工、不再分配工时。理由、前后数量、动作来源及工时校验结果留审计记录。

存在返工报工/领取、物料、后续分支、其他业务、待处理撤回、正式质检或不完整核销等情况时阻断；部分已释放的良品保持原有流转。过期预览、跨范围、未登录、缺少权限、跨站提交及重复请求均有校验。作废分支不能继续报工。后续数量不足时保持未完成，不强制完结。

闭环核对器兼容保留历史的作废返工分支，以及同一报工多次释放数量；动作工时核对口径与现有实际动作计工服务一致，未改工时统计公式。采购与库存业务代码未改，无数据库结构迁移。

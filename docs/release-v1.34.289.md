# v1.34.289 追加业务权限与生产兼岗保留

基于最新成功发布的 v1.34.288（`62f6300705a872ff9792dba2f64a914939c08097`），保留其他工时批量同意与加载优化。

## 变更

已有非生产部门员工经管理员明确授予本人生产兼岗后，编辑业务模块会保留有效的扫码报工授权。保留原授权 ID、员工范围、生产职责部门、起止时间和授权类型；不修改员工档案部门、身份或密码。未授权、已失效、已停用或属于其他员工的授权不能借此开通；明确关闭扫码仍会撤销。

本次没有修改工时计算、报表统计、单笔或批量审批业务规则，也没有新增数据库迁移或环境变量。实际账号授权通过现有管理界面与管理员授权接口保存，镜像不内置个人账号、权限快照或凭据。
